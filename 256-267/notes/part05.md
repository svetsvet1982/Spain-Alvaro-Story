## 장면 13. 접선자의 정체와 배후
> 체포 다음 날, 카를로스가 접선자의 신원과 배후 조직에 대한 정보를 알바로에게 전합니다.

### 13-1. **Carlos:** (Llama) Álvaro, tenemos la identidad real del contacto de Elena.
- **해석:** (전화를 건다) 알바로, 엘레나 접선자의 진짜 신원을 알아냈어.
- **주요 단어:** `llamar` (동사) 전화하다 / `identidad` (명사, 여) 신원, 정체 / `real` (형용사) 실제의, 진짜의 / `contacto` (명사, 남) 연락책, 접선자
- **문법:** `tener`가 "알아내다·확보하다"의 의미로 쓰임. `de Elena` 소유 전치사 de.
- **표현:** `tenemos` + 정보 = "~을 확보했다/알아냈다"는 구어적 표현.
- **시제:** `Llama` → llamar, 직설법 현재 3인칭 단수(지문) / `tenemos` → tener, 직설법 현재 1인칭 복수

### 13-2. **Álvaro:** ¿Quién es?
- **해석:** 누구야?
- **주요 단어:** `quién` (의문대명사) 누구
- **문법:** 의문사 quién + ser. 특이사항 없음.
- **시제:** `es` → ser, 직설법 현재 3인칭 단수

### 13-3. **Carlos:** Un intermediario independiente, sin vínculo directo con ningún servicio de inteligencia estatal.
- **해석:** 독립 중개인이야. 어떤 국가 정보기관과도 직접적인 연관은 없어.
- **주요 단어:** `intermediario` (명사, 남) 중개인, 브로커 / `independiente` (형용사) 독립적인 / `vínculo` (명사, 남) 연결, 유대 / `servicio de inteligencia` 정보기관 / `estatal` (형용사) 국가의
- **문법:** `sin` + 명사 = ~ 없이. `ningún`(ninguno의 남성 단수 명사 앞 탈락형)은 부정문 맥락(sin)에서 "어떤 ~도".
- **표현:** 앞 질문에 대한 답이라 `Es`가 생략된 명사구 문장.
- **시제:** 동사 없음

### 13-4. **Carlos:** Trabaja para el mejor postor.
- **해석:** 가장 높은 값을 부르는 쪽을 위해 일하지.
- **주요 단어:** `trabajar` (동사) 일하다 / `postor` (명사, 남) 입찰자
- **문법:** `para` 목적·대상("~을 위해"). `el mejor` 최상급.
- **표현:** `al mejor postor` = "최고 입찰자에게" (경매 표현). 돈만 주면 누구에게든 판다는 뉘앙스.
- **시제:** `Trabaja` → trabajar, 직설법 현재 3인칭 단수

### 13-5. **Álvaro:** ¿Y quién era el comprador final?
- **해석:** 그럼 최종 구매자는 누구였어?
- **주요 단어:** `comprador` (명사, 남) 구매자 / `final` (형용사) 최종의
- **문법:** 과거의 상태·정체를 묻기 때문에 불완료과거 `era` 사용.
- **표현:** 문두 `Y` = "그럼, 그리고" 질문을 이어가는 구어적 연결.
- **시제:** `era` → ser, 직설법 불완료과거 3인칭 단수

### 13-6. **Carlos:** Según lo que ha empezado a confesar, un consorcio energético extranjero interesado en analizar vulnerabilidades de diseño para su propia ventaja competitiva.
- **해석:** 그가 자백하기 시작한 바에 따르면, 자기들의 경쟁 우위를 위해 설계상 취약점을 분석하려던 외국 에너지 컨소시엄이야.
- **주요 단어:** `según` (전치사) ~에 따르면 / `confesar` (동사) 자백하다 / `consorcio` (명사, 남) 컨소시엄, 기업 연합 / `energético` (형용사) 에너지의 / `extranjero` (형용사) 외국의 / `vulnerabilidad` (명사, 여) 취약점 / `diseño` (명사, 남) 설계 / `ventaja competitiva` 경쟁 우위
- **문법:** `lo que` 중성 관계사 "~한 것". `empezar a` + 부정사 = ~하기 시작하다. `interesado en` + 부정사 = ~에 관심 있는. `su propia` = 자기 자신의(강조).
- **표현:** 주어+동사(Era) 생략된 답변형 명사구.
- **시제:** `ha empezado` → empezar, 직설법 현재완료 3인칭 단수 / `confesar` → 부정사 / `interesado` → interesar, 과거분사(형용사적 용법) / `analizar` → 부정사

### 13-7. **Álvaro:** Entonces no era sabotaje directo, sino espionaje industrial puro.
- **해석:** 그러니까 직접적인 사보타주가 아니라 순수한 산업 스파이 행위였네.
- **주요 단어:** `sabotaje` (명사, 남) 사보타주, 파괴 공작 / `espionaje` (명사, 남) 스파이 행위, 첩보 / `industrial` (형용사) 산업의 / `puro` (형용사) 순수한, 완전한
- **문법:** `no A, sino B` = A가 아니라 B (부정 후 정정할 때 pero가 아니라 sino).
- **표현:** `puro`가 명사 뒤에 와서 "순전한, 그야말로 ~" 뉘앙스.
- **시제:** `era` → ser, 직설법 불완료과거 3인칭 단수

### 13-8. **Carlos:** Eso parece, aunque no descartamos que la información pudiera haberse revendido después a terceros con intenciones menos comerciales.
- **해석:** 그런 것 같아. 다만 그 정보가 나중에 덜 상업적인 의도를 가진 제3자에게 되팔렸을 가능성도 배제하지 않고 있어.
- **주요 단어:** `parecer` (동사) ~인 것 같다 / `descartar` (동사) 배제하다 / `revender` (동사) 되팔다 / `terceros` (명사, 남·복) 제3자 / `intención` (명사, 여) 의도
- **문법:** `no descartar que` + 접속법 (가능성·불확실성 표현 → 접속법). `pudiera haberse revendido` = poder 접속법 불완료과거 + 완료부정사(수동 se) → "되팔렸을 수도 있다"는 과거 가능성. `menos` + 형용사 = 덜 ~한.
- **표현:** `Eso parece` = "그런 것 같아" (단답형 관용). `aunque` = 다만, ~이긴 하지만.
- **시제:** `parece` → parecer, 직설법 현재 3인칭 단수 / `descartamos` → descartar, 직설법 현재 1인칭 복수 / `pudiera` → poder, 접속법 불완료과거 3인칭 단수 / `haberse revendido` → revender, 완료부정사(재귀·수동 se, haber + 과거분사)

### 13-9. **Álvaro:** ¿La central está en riesgo real, dado lo que ya se filtró?
- **해석:** 이미 유출된 걸 감안하면, 발전소가 실제로 위험한 상태야?
- **주요 단어:** `central` (명사, 여) 발전소 (central nuclear의 줄임) / `riesgo` (명사, 남) 위험 / `filtrar(se)` (동사) 유출되다
- **문법:** `estar en riesgo` 상태 표현이라 estar. `dado lo que` = ~을 고려하면(dado는 dar의 과거분사로 전치사처럼 쓰임). `se filtró` 수동 재귀.
- **표현:** `dado que` / `dado lo que` = "~인 점을 감안하면" 격식체.
- **시제:** `está` → estar, 직설법 현재 3인칭 단수 / `dado` → dar, 과거분사 / `se filtró` → filtrarse, 직설법 단순과거 3인칭 단수

### 13-10. **Carlos:** Los ingenieros están revisando si es necesario modificar algún protocolo, como medida de precaución.
- **해석:** 엔지니어들이 예방 차원에서 어떤 프로토콜을 수정할 필요가 있는지 검토하고 있어.
- **주요 단어:** `ingeniero` (명사, 남) 엔지니어 / `revisar` (동사) 검토하다 / `modificar` (동사) 수정하다 / `protocolo` (명사, 남) 절차, 프로토콜 / `medida` (명사, 여) 조치 / `precaución` (명사, 여) 예방, 주의
- **문법:** `estar + 현재분사` 진행형. `si` = ~인지 아닌지(간접의문). `es necesario + 부정사` 무인칭 구문. `algún` = alguno 탈락형.
- **표현:** `como medida de precaución` = 예방 조치로서.
- **시제:** `están revisando` → revisar, 직설법 현재진행 3인칭 복수(estar 현재 + 현재분사) / `es` → ser, 직설법 현재 3인칭 단수 / `modificar` → 부정사

### 13-11. **Carlos:** Pero no hay indicios de sabotaje inminente.

### 13-12. **Álvaro:** Menos mal.
- **해석:** 다행이다.

### 13-13. **Carlos:** Buen trabajo, Álvaro.
- **해석:** 수고했어, 알바로.
- **주요 단어:** `trabajo` (명사, 남) 일

### 13-14. **Carlos:** Este ha sido, sin duda, el caso de mayor riesgo potencial que hemos llevado juntos.

- **표현:** `llevar un caso` = 사건을 담당하다. 스페인식 현재완료로 막 끝난 사건 평가.
- **시제:** `ha sido` → ser, 직설법 현재완료 3인칭 단수 / `hemos llevado` → llevar, 직설법 현재완료 1인칭 복수

## 장면 14. 마우리시오와의 마지막 만남
> 알바로가 마우리시오와 마지막으로 만나 감사장 사업 마무리를 정리합니다.

### 14-1. **Mauricio:** Señor Romero, o debería decir... Álvaro Fuentes, según me han informado.
- **해석:** 로메로 씨, 아니 이렇게 불러야 할까요… 제가 들은 바로는 알바로 푸엔테스 씨라고요.
- **주요 단어:** `deber` (동사) ~해야 하다 / `decir` (동사) 말하다 / `según` 앞에서 설명 / `informar` (동사) 알리다
- **문법:** 조건법 `debería`는 공손·완곡 표현. `me han informado` 3인칭 복수 무인칭(누가 알렸는지 특정하지 않음), me는 간접목적어.
- **표현:** `o debería decir...` = "아니, ~라고 해야 하나요" 정정하며 농담조로 부르는 표현.
- **시제:** `debería` → deber, 조건법 현재 1인칭 단수 / `decir` → 부정사 / `han informado` → informar, 직설법 현재완료 3인칭 복수

### 14-2. **Álvaro:** (Sonríe) Culpable.

- **문법:** 특이사항 없음

- **시제:** `Sonríe` → sonreír, 직설법 현재 3인칭 단수(지문)

### 14-3. **Álvaro:** Lamento la confusión inicial.
- **해석:** 처음에 혼란을 드려 죄송합니다.
- **주요 단어:** `lamentar` (동사) 유감스럽게 여기다 / `confusión` (명사, 여) 혼란 / `inicial` (형용사) 처음의

### 14-4. **Mauricio:** En absoluto.

- **시제:** 동사 없음

### 14-5. **Mauricio:** Gracias a su auditoría, identificamos una brecha que llevaba semanas activa sin que lo supiéramos.
- **해석:** 당신의 감사 덕분에, 우리도 모르는 사이 몇 주 동안 열려 있던 보안 구멍을 찾아냈습니다.
- **주요 단어:** `gracias a` ~ 덕분에 / `auditoría` (명사, 여) 감사, 점검 / `identificar` (동사) 확인하다, 찾아내다 / `brecha` (명사, 여) 틈, 보안 허점 / `activo` (형용사) 활성의
- **문법:** `llevar + 기간 + 형용사` = ~한 상태로 (기간)째이다. `sin que` + 접속법(항상 접속법). 과거 문맥이라 접속법 불완료과거. `lo`는 앞 내용 전체를 받는 중성 대명사.

### 14-6. **Álvaro:** Fue un trabajo en equipo, con el CNI y con toda su colaboración.
- **해석:** 팀워크였죠. CNI와 함께, 그리고 전적으로 협조해 주신 덕분이에요.
- **주요 단어:** `trabajo en equipo` 팀워크 / `colaboración` (명사, 여) 협조, 협력 / `CNI` 스페인 국가정보원(Centro Nacional de Inteligencia)

### 14-9. **Álvaro:** Este tipo de vulnerabilidad puede repetirse en cualquier momento, en cualquier instalación.

- **시제:** `Espero` → esperar, 직설법 현재 1인칭 단수 / `tener` → 부정사 / `volver` → 부정사 / `llamarlo` → llamar, 부정사 + 목적대명사
