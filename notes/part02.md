## 장면 2. 이그나시오의 미술사 속성 교육
> 알바로(이제부터 '다니엘')가 카를로스가 소개한 미술사 전문가 이그나시오(Ignacio)에게 2주간 속성 교육을 받는 장면입니다. 페루 콜럼버스 이전 문화, 진위 감정법, 경매 용어까지 위장 신분에 필요한 지식을 압축적으로 학습합니다.

### 2-1. **Ignacio:** Bueno, Daniel, empecemos por lo básico.
- **해석:** 자, 다니엘, 기초부터 시작합시다.
- **주요 단어:** `bueno` (감탄사) 자, 그럼 / `empezar` (동사) 시작하다 / `lo básico` (명사구) 기본적인 것, 기초
- **문법:** `empecemos`는 접속법 현재 1인칭 복수로 만든 nosotros 명령형("~합시다"). `lo + 형용사`는 추상명사화("~한 것"). `empezar por` = ~부터 시작하다.
- **표현:** 대화를 시작할 때 쓰는 "Bueno, ..."는 "자, 그럼" 정도의 도입 표현.
- **시제:** `empecemos` → empezar, 명령법(접속법 현재 형태) 1인칭 복수 (z→c 철자 변화)

### 2-2. **Ignacio:** ¿Qué sabes de arte precolombino, para empezar de cero contigo?
- **해석:** 너와 처음부터 시작하려는 건데, 콜럼버스 이전 미술에 대해 뭘 알고 있니?
- **주요 단어:** `saber` (동사) 알다 / `arte precolombino` (명사구) 콜럼버스 이전(아메리카 정복 이전) 미술 / `de cero` 처음부터, 무(無)에서 / `contigo` (대명사) 너와 함께
- **문법:** `saber de + 명사` = ~에 대해 알다. `para + 동사원형` = 목적("~하기 위해"). `contigo`는 con + ti의 특수형.
- **표현:** `empezar de cero` = 맨 처음부터 시작하다. 이그나시오는 처음부터 tú(반말)를 사용.
- **시제:** `sabes` → saber, 직설법 현재 2인칭 단수 / `empezar` → 동사원형

### 2-3. **Álvaro:** Prácticamente nada, se lo confieso.
- **해석:** 사실상 아무것도 모릅니다, 솔직히 말씀드리면요.
- **주요 단어:** `prácticamente` (부사) 사실상, 거의 / `nada` (대명사) 아무것도 / `confesar` (동사) 고백하다, 털어놓다
- **문법:** `se lo confieso`: 간접목적대명사 le가 직접목적대명사 lo 앞에서 se로 바뀜(le lo → se lo). se = a usted, lo = 그 사실(중성). 대명사는 활용동사 앞에 위치.
- **표현:** `se lo confieso` = "솔직히 고백하자면". 알바로는 usted(존칭)를 사용.
- **시제:** `confieso` → confesar, 직설법 현재 1인칭 단수 (e→ie 어간 변화)

### 2-4. **Álvaro:** Sé que existieron los incas, poco más.
- **해석:** 잉카인들이 존재했다는 것 정도, 그 이상은 별로 모릅니다.
- **주요 단어:** `existir` (동사) 존재하다 / `los incas` (명사) 잉카인 / `poco más` 그 이상은 거의 없음
- **문법:** `saber que + 직설법` 명사절. 과거에 완결된 사실이므로 부정과거(단순과거) 사용.
- **표현:** 문장 끝의 `poco más`는 "그게 다예요, 그 이상은 별로"라는 구어적 덧붙임.
- **시제:** `sé` → saber, 직설법 현재 1인칭 단수 (불규칙) / `existieron` → existir, 직설법 부정과거(단순과거) 3인칭 복수

### 2-5. **Ignacio:** Perfecto, así no tengo que corregir ideas equivocadas.
- **해석:** 좋아, 그러면 잘못된 생각을 바로잡을 필요가 없겠군.
- **주요 단어:** `perfecto` (형용사) 완벽한, 좋아 / `así` (부사) 그렇게 하면, 그러면 / `corregir` (동사) 고치다, 바로잡다 / `equivocado` (형용사) 잘못된, 틀린
- **문법:** `tener que + 동사원형` = ~해야 한다 (부정문: ~할 필요가 없다). `equivocadas`는 equivocar의 과거분사가 형용사로 쓰여 ideas에 성·수 일치.
- **표현:** `Perfecto`는 "좋아, 잘됐네"의 구어적 반응.
- **시제:** `tengo` → tener, 직설법 현재 1인칭 단수 (불규칙) / `corregir` → 동사원형 / `equivocadas` → equivocar, 과거분사(여성 복수, 형용사 용법)

### 2-6. **Ignacio:** Empecemos por las culturas peruanas más relevantes para este caso: moche, nazca y chimú.
- **해석:** 이번 사건에 가장 관련이 깊은 페루 문화들부터 시작하자. 모체, 나스카, 치무야.
- **주요 단어:** `cultura` (명사) 문화 / `peruano` (형용사) 페루의 / `relevante` (형용사) 관련 있는, 중요한 / `caso` (명사) 사건, 경우
- **문법:** `las + 명사 + más + 형용사` = 최상급("가장 ~한"). `empecemos por` 앞에서 설명(nosotros 명령형).
- **표현:** 고대 문화 이름(moche, nazca, chimú)은 소문자로 쓰는 경우가 많음.
- **시제:** `empecemos` → empezar, 명령법 1인칭 복수 (앞에서 설명)

### 2-7. **Álvaro:** ¿Y esas son anteriores a los incas?
- **해석:** 그럼 그 문화들은 잉카보다 이전인가요?
- **주요 단어:** `anterior` (형용사) 이전의, 앞선
- **문법:** `anterior a` = ~보다 이전의 (비교 대상에 전치사 a 사용; posterior a도 동일). `esas`는 culturas를 받는 지시대명사. 본질적 성질·분류이므로 ser.
- **표현:** 문장 첫머리 `¿Y ...?`는 "그럼 ~는요?" 식으로 질문을 이어가는 구어체.
- **시제:** `son` → ser, 직설법 현재 3인칭 복수

### 2-8. **Ignacio:** Mucho antes.
- **해석:** 훨씬 이전이지.
- **주요 단어:** `mucho` (부사) 훨씬 / `antes` (부사) 전에
- **문법:** `mucho`가 비교 부사 antes를 강조("훨씬 ~").
- **시제:** 동사 없음

### 2-9. **Ignacio:** Los moche, por ejemplo, florecieron entre los siglos I y VIII después de Cristo.
- **해석:** 예를 들어 모체인들은 기원후 1세기에서 8세기 사이에 번성했어.
- **주요 단어:** `florecer` (동사) 꽃피다, 번성하다 / `siglo` (명사) 세기 / `después de Cristo` 기원후(d.C.)
- **문법:** `entre A y B` = A와 B 사이. 세기는 로마 숫자로 쓰며, 보통 10세기까지는 서수(siglo primero, siglo octavo)로, 11세기부터는 기수(siglo once)로 읽음. 과거의 완결된 기간이므로 부정과거.
- **표현:** `después de Cristo`(d.C.) ↔ `antes de Cristo`(a.C.) 기원전.
- **시제:** `florecieron` → florecer, 직설법 부정과거 3인칭 복수

### 2-10. **Ignacio:** Son famosos por su cerámica, sobre todo los llamados "huaco retrato".
- **해석:** 그들은 도자기로 유명한데, 특히 이른바 '와코 레트라토'가 그래.
- **주요 단어:** `famoso` (형용사) 유명한 / `cerámica` (명사) 도자기 / `sobre todo` (부사구) 특히 / `llamado` (형용사) 이른바, ~라고 불리는 / `huaco` (명사) 와코(페루 고대 유적 출토 토기)
- **문법:** `ser famoso por` = ~로 유명하다(원인의 por). `los llamados + 명사` = "이른바 ~라고 불리는 것들" (과거분사의 형용사 용법).
- **표현:** `huaco retrato` = 인물 얼굴을 본뜬 초상 토기.
- **시제:** `son` → ser, 직설법 현재 3인칭 복수 / `llamados` → llamar, 과거분사(남성 복수, 형용사 용법)

### 2-11. **Álvaro:** ¿Qué es un huaco retrato?
- **해석:** 와코 레트라토가 뭔가요?
- **주요 단어:** `huaco retrato` (명사) 초상 토기 (앞에서 설명)
- **문법:** 정의를 묻는 `¿Qué es ...?` 구문(ser).
- **시제:** `es` → ser, 직설법 현재 3인칭 단수

### 2-12. **Ignacio:** Una vasija de cerámica con forma de rostro humano, extremadamente realista.
- **해석:** 사람 얼굴 모양을 한 도자기 그릇이야, 굉장히 사실적이지.
- **주요 단어:** `vasija` (명사) 그릇, 용기 / `forma` (명사) 모양 / `rostro` (명사) 얼굴 / `humano` (형용사) 인간의 / `extremadamente` (부사) 극도로 / `realista` (형용사) 사실적인
- **문법:** 동사가 생략된 명사구 답변(= Es una vasija...). `con forma de` = ~ 모양의. `realista`는 -ista로 끝나는 남녀 동형 형용사.
- **시제:** 동사 없음

### 2-13. **Ignacio:** Son de las piezas más buscadas y, por desgracia, más falsificadas.
- **해석:** 가장 많이 찾는 작품 중 하나이고, 불행히도 가장 많이 위조되는 것 중 하나야.
- **주요 단어:** `pieza` (명사) (미술)작품, 조각 / `buscado` (형용사) 인기 있는, 많이 찾는 / `por desgracia` 불행히도 / `falsificado` (형용사) 위조된
- **문법:** `ser de + 정관사 + 명사 + más ~` = "가장 ~한 것들 중 하나이다". 과거분사 buscadas, falsificadas가 piezas(여성 복수)에 일치.
- **표현:** `por desgracia` = desgraciadamente, "안타깝게도".
- **시제:** `son` → ser, 직설법 현재 3인칭 복수 / `buscadas` → buscar, 과거분사(여성 복수) / `falsificadas` → falsificar, 과거분사(여성 복수)

### 2-14. **Álvaro:** ¿Y cómo se distingue una pieza auténtica de una falsificación?
- **해석:** 그럼 진품과 위조품은 어떻게 구별하나요?
- **주요 단어:** `distinguir` (동사) 구별하다 / `auténtico` (형용사) 진짜의 / `falsificación` (명사) 위조, 위조품
- **문법:** `se distingue`는 무인칭/수동의 se("사람들이 ~하다, ~되다"). `distinguir A de B` = A를 B와 구별하다.
- **시제:** `distingue` → distinguir, 직설법 현재 3인칭 단수 (gu 철자 유지)

### 2-15. **Ignacio:** Hay varios indicadores.
- **해석:** 여러 가지 지표가 있어.
- **주요 단어:** `haber` (동사) 있다 / `varios` (형용사) 여러 / `indicador` (명사) 지표, 표시
- **문법:** 존재를 나타내는 무인칭 `hay`(haber) — 뒤의 명사가 복수여도 형태는 hay.
- **시제:** `hay` → haber, 직설법 현재 3인칭 단수(무인칭)

### 2-16. **Ignacio:** El primero es la pátina: el desgaste natural que deja el paso del tiempo y el contacto con la tierra.
- **해석:** 첫 번째는 파티나야. 세월이 흐르고 흙과 접촉하면서 생기는 자연스러운 마모 흔적이지.
- **주요 단어:** `pátina` (명사) 파티나, 표면의 세월 흔적(녹청) / `desgaste` (명사) 마모, 닳음 / `dejar` (동사) 남기다 / `paso` (명사) 흐름, 경과 / `contacto` (명사) 접촉 / `tierra` (명사) 흙, 땅
- **문법:** 관계대명사 `que`가 desgaste를 받는 목적어. 관계절 안에서 주어(el paso del tiempo y el contacto con la tierra)가 동사 뒤로 도치됨. 콜론(:)으로 부연 설명.
- **표현:** `el paso del tiempo` = 세월의 흐름.
- **시제:** `es` → ser, 직설법 현재 3인칭 단수 / `deja` → dejar, 직설법 현재 3인칭 단수

### 2-17. **Ignacio:** Es muy difícil de falsificar bien.
- **해석:** 그걸 제대로 위조하기는 아주 어려워.
- **주요 단어:** `difícil` (형용사) 어려운 / `falsificar` (동사) 위조하다
- **문법:** `ser difícil de + 동사원형` = "~하기 어렵다"(주어가 동작의 대상일 때 de 사용). 비교: Es difícil falsificarla(비인칭, de 없음).
- **시제:** `es` → ser, 직설법 현재 3인칭 단수 / `falsificar` → 동사원형

### 2-18. **Álvaro:** ¿Y los falsificadores no pueden imitar eso?
- **해석:** 그럼 위조범들은 그걸 흉내 낼 수 없나요?
- **주요 단어:** `falsificador` (명사) 위조범 / `poder` (동사) ~할 수 있다 / `imitar` (동사) 모방하다
- **문법:** `poder + 동사원형`. 중성 지시대명사 `eso` = 앞에서 말한 그것(파티나).
- **시제:** `pueden` → poder, 직설법 현재 3인칭 복수 (o→ue) / `imitar` → 동사원형

### 2-19. **Ignacio:** Lo intentan, pero un ojo entrenado suele notar la diferencia.
- **해석:** 시도는 하지만, 훈련된 눈은 보통 그 차이를 알아차려.
- **주요 단어:** `intentar` (동사) 시도하다 / `ojo` (명사) 눈 / `entrenado` (형용사) 훈련된 / `soler` (동사) 보통 ~하다 / `notar` (동사) 알아차리다 / `diferencia` (명사) 차이
- **문법:** `lo`는 중성 직접목적대명사(= 그렇게 하는 것, 모방하는 것). `soler + 동사원형` = 습관·경향("대개 ~하다").
- **표현:** `un ojo entrenado` = 전문가의 눈, 안목.
- **시제:** `intentan` → intentar, 직설법 현재 3인칭 복수 / `suele` → soler, 직설법 현재 3인칭 단수 (o→ue) / `notar` → 동사원형 / `entrenado` → entrenar, 과거분사(형용사 용법)

### 2-20. **Ignacio:** La pátina auténtica tiene una irregularidad natural que las técnicas artificiales no reproducen del todo.
- **해석:** 진짜 파티나에는 인공적인 기법으로는 완전히 재현할 수 없는 자연스러운 불규칙성이 있어.
- **주요 단어:** `irregularidad` (명사) 불규칙성 / `técnica` (명사) 기법 / `artificial` (형용사) 인공적인 / `reproducir` (동사) 재현하다 / `del todo` 완전히
- **문법:** 관계대명사 `que`(목적격)가 irregularidad를 받음. `no ... del todo` = "완전히 ~하지는 않다"(부분부정).
- **시제:** `tiene` → tener, 직설법 현재 3인칭 단수 / `reproducen` → reproducir, 직설법 현재 3인칭 복수

### 2-21. **Álvaro:** Entiendo.
- **해석:** 알겠습니다.
- **주요 단어:** `entender` (동사) 이해하다
- **문법:** 특이사항 없음
- **시제:** `entiendo` → entender, 직설법 현재 1인칭 단수 (e→ie)

### 2-22. **Álvaro:** ¿Qué más debo saber?
- **해석:** 그 밖에 뭘 알아야 하나요?
- **주요 단어:** `qué más` 그 밖에 무엇 / `deber` (동사) ~해야 한다
- **문법:** `deber + 동사원형` = 의무("~해야 한다").
- **시제:** `debo` → deber, 직설법 현재 1인칭 단수 / `saber` → 동사원형

### 2-23. **Ignacio:** La procedencia.
- **해석:** 출처야.
- **주요 단어:** `procedencia` (명사) 출처, 유래, (미술품의) 소장 이력
- **문법:** 동사가 생략된 명사 답변(= Lo segundo es la procedencia).

- **주요 단어:** `suponerse` (동사) ~인 것으로 되어 있다 / `llevar + 시간 + 현재분사` ~해 온 지 …되다 / `coleccionar` (동사) 수집하다 / `estudiar` (동사) 공부하다 / `según` (전치사) ~에 따르면 / `tapadera` (명사) 위장, 은폐용 신분
- **문법:** `se supone que` = "~인 것으로 되어 있다"(무인칭 se). `llevar + 기간 + 현재분사` = 지속 기간 표현("~한 지 얼마나 되다").
- **표현:** `tapadera` = (스파이·잠입) 위장 신분, 구어적 표현.
- **시제:** `supone` → suponer, 직설법 현재 3인칭 단수 (무인칭 se) / `llevo` → llevar, 직설법 현재 1인칭 단수 / `coleccionando` → coleccionar, 현재분사 / `estudiando` → estudiar, 현재분사

### 2-46. **Ignacio:** El tiempo suficiente para tener conocimiento sólido, pero no tanto como para que esperen que conozcas a todo el mundo del sector.
- **해석:** 탄탄한 지식을 갖추기엔 충분하지만, 업계 사람을 다 알고 있으리라 기대받을 만큼 길지는 않은 시간이지.
- **주요 단어:** `suficiente` (형용사) 충분한 / `conocimiento` (명사) 지식 / `sólido` (형용사) 견고한, 탄탄한 / `esperar` (동사) 기대하다 / `conocer` (동사) (사람을) 알다 / `todo el mundo` 모든 사람 / `sector` (명사) 업계, 분야
- **문법:** `no tanto como para que + 접속법` = "~할 정도로 그렇게 많지는 않은". `esperar que + 접속법` → `conozcas`. 사람 목적어 앞 인칭 a(`a todo el mundo`). 
- **표현:** `todo el mundo del sector` = 업계의 모든 사람.
- **시제:** `tener` → 동사원형 / `esperen` → esperar, 접속법 현재 3인칭 복수 / `conozcas` → conocer, 접속법 현재 2인칭 단수 (c→zc)

### 2-48. **Álvaro:** ¿Algún error común que debería evitar?
- **해석:** 제가 피해야 할 흔한 실수가 있을까요?
- **주요 단어:** `algún` (형용사) 어떤 (alguno의 어미 탈락형) / `error` (명사) 실수 / `común` (형용사) 흔한 / `evitar` (동사) 피하다
- **문법:** `alguno`는 남성 단수 명사 앞에서 `algún`. 관계대명사 `que` + 조건법(완곡). 동사(¿Hay ...?) 생략.
- **시제:** `debería` → deber, 조건법 1인칭 단수 / `evitar` → 동사원형
