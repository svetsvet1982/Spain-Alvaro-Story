## 장면 7. 치무 칼의 공개와 중개인의 이름
> 리셉션 이후 몇 주가 지나, 세르히오가 다니엘을 다시 초대해 좀 더 깊은 대화를 나눕니다. 신뢰가 쌓이면서 세르히오가 치무 칼의 실물을 처음으로 보여주고, 조직의 운영 방식에 대해 조금씩 더 털어놓습니다.

### 7-1. **Sergio:** Daniel, gracias por venir con tan poco aviso.
- **해석:** 다니엘, 이렇게 급하게 연락드렸는데 와 주셔서 감사합니다.
- **주요 단어:** `gracias` (명사) 감사 / `venir` (동사) 오다 / `aviso` (명사) 알림, 통지 / `tan poco` 그토록 적은
- **문법:** `gracias por + 동사원형` = ~해 주어서 고맙다. 전치사 뒤에는 동사원형이 온다. `con tan poco aviso` = "이렇게 적은 통지로", 즉 촉박한 연락에도.
- **표현:** `con poco aviso` = 촉박하게, 갑작스럽게 알려서. 세르히오는 다니엘에게 계속 usted(존칭)를 쓴다.
- **시제:** `venir` → venir, 동사원형

### 7-2. **Sergio:** Quería enseñarle algo, en privado.
- **해석:** 따로 보여드리고 싶은 게 있었습니다.
- **주요 단어:** `enseñar` (동사) 보여 주다, 가르치다 / `algo` (대명사) 무언가 / `en privado` 사적으로, 단둘이
- **문법:** `enseñarle`: 간접목적대명사 `le`(= a usted)가 동사원형 뒤에 붙음. `querer + 동사원형` = ~하고 싶다.
- **표현:** `Quería...` 불완료과거는 현재의 바람을 공손하게 표현하는 용법(“~하고 싶었는데요”). 스페인에서는 `enseñar`를 "보여주다(mostrar)" 뜻으로 흔히 씀.
- **시제:** `Quería` → querer, 직설법 불완료과거 1인칭 단수 / `enseñar` → enseñar, 동사원형

- **문법:** 특이사항 없음
- **표현:** 동의·수락의 정중한 표현.
- **시제:** 동사 없음

### 7-4. **Álvaro:** Suena intrigante.
- **해석:** 흥미롭게 들리네요.
- **주요 단어:** `sonar` (동사) 들리다, 소리 나다 / `intrigante` (형용사) 호기심을 자아내는
- **문법:** `sonar + 형용사` = ~하게 들리다. 주어(그것)가 생략됨. sonar는 o→ue 어간변화 동사.
- **시제:** `Suena` → sonar, 직설법 현재 3인칭 단수

### 7-5. **Sergio:** (Abre una caja forrada de terciopelo) Aquí está.
- **해석:** (벨벳으로 안을 댄 상자를 연다) 여기 있습니다.
- **주요 단어:** `abrir` (동사) 열다 / `caja` (명사) 상자 / `forrado` (forrar의 과거분사·형용사) 안감을 댄 / `terciopelo` (명사) 벨벳
- **문법:** `forrada de terciopelo`: 과거분사가 형용사로 쓰여 `caja`(여성 단수)와 성·수 일치. `Aquí está` = 여기 있다(위치이므로 estar).
- **시제:** `Abre` → abrir, 직설법 현재 3인칭 단수 / `forrada` → forrar, 과거분사(여성 단수) / `está` → estar, 직설법 현재 3인칭 단수

### 7-6. **Sergio:** El cuchillo ceremonial chimú del que le hablé.
- **해석:** 제가 말씀드렸던 그 치무 의식용 칼입니다.
- **주요 단어:** `cuchillo` (명사) 칼 / `ceremonial` (형용사) 의식용의 / `chimú` (형용사) 치무(페루 북부 고대 문명)의 / `hablar de` ~에 대해 말하다
- **문법:** 관계사 `del que` = de + el que. `hablar de algo`의 전치사 de가 관계사 앞으로 온 형태("~에 대해 말한 그 칼"). `le` = a usted(간접목적).
- **시제:** `hablé` → hablar, 직설법 부정과거(단순과거) 1인칭 단수

### 7-7. **Álvaro:** (Examinándolo con auténtico asombro, aunque también profesional) Es... extraordinario.
- **해석:** (진짜 감탄하면서도 전문가다운 태도로 살펴보며) 이건… 대단하네요.
- **주요 단어:** `examinar` (동사) 살펴보다 / `auténtico` (형용사) 진정한 / `asombro` (명사) 놀라움 / `aunque` (접속사) ~이지만 / `extraordinario` (형용사) 비범한, 대단한
- **문법:** `Examinándolo`: 현재분사 + 직접목적대명사 `lo`(= el cuchillo). 대명사가 붙으면서 강세 표시(á) 추가.
- **시제:** `Examinándolo` → examinar, 현재분사(gerundio) / `Es` → ser, 직설법 현재 3인칭 단수

### 7-8. **Álvaro:** El trabajo en oro es increíblemente fino.

- **문법:** 사물의 본질적 성질이므로 ser. `en oro` = 금으로 된(재료).
- **시제:** `es` → ser, 직설법 현재 3인칭 단수

- **표현:** `¿Verdad que sí?` = 상대의 동의를 확인하는 구어 표현("정말 그렇지 않나요?").

### 7-10. **Sergio:** Llevo semanas sin poder dejar de mirarlo cada vez que lo tengo cerca.
- **해석:** 몇 주째 이걸 가까이 두기만 하면 눈을 뗄 수가 없어요.
- **주요 단어:** `llevar` (동사) (시간을) 보내다 / `semana` (명사) 주 / `dejar de` ~을 그만두다 / `mirar` (동사) 보다 / `cada vez que` ~할 때마다 / `cerca` (부사) 가까이
- **문법:** `llevar + 기간 + sin + 동사원형` = ~째 ~하지 못하고 있다. `dejar de + 동사원형` = ~하기를 멈추다. `mirarlo`: 원형 뒤에 lo 부착. `lo tengo cerca`: 목적대명사가 활용 동사 앞.
- **표현:** `no poder dejar de + 동사` = ~하지 않을 수 없다, 계속 ~하게 된다.
- **시제:** `Llevo` → llevar, 직설법 현재 1인칭 단수 / `poder` → poder, 동사원형 / `dejar` → dejar, 동사원형 / `mirarlo` → mirar, 동사원형 / `tengo` → tener, 직설법 현재 1인칭 단수

### 7-11. **Álvaro:** (Recordando las lecciones de Ignacio) La iconografía del mango, ¿son figuras de deidades marinas?
- **해석:** (이그나시오의 수업을 떠올리며) 손잡이의 도상 말인데요, 바다 신들의 형상인가요?
- **주요 단어:** `recordar` (동사) 기억하다, 떠올리다 / `lección` (명사) 수업 / `iconografía` (명사) 도상(학) / `mango` (명사) 손잡이 / `figura` (명사) 형상 / `deidad` (명사) 신 / `marino` (형용사) 바다의
- **문법:** 주제를 먼저 제시한 뒤 질문하는 구조(`La iconografía..., ¿son...?`). 동사는 뒤의 `figuras`(복수)에 맞춰 `son`.
- **표현:** `mango`는 과일 망고와 동음이의어로 "손잡이"도 뜻함.
- **시제:** `Recordando` → recordar, 현재분사 / `son` → ser, 직설법 현재 3인칭 복수

- **문법:** 특이사항 없음

### 7-13. **Sergio:** Veo que ha seguido estudiando desde la última vez que hablamos.
- **해석:** 지난번에 이야기 나눈 뒤로도 계속 공부하셨군요.
- **주요 단어:** `ver` (동사) 보다, 알다 / `seguir` (동사) 계속하다 / `estudiar` (동사) 공부하다 / `desde` (전치사) ~이후로 / `última vez` 지난번
- **문법:** `seguir + 현재분사` = 계속 ~하다. `ha seguido`: 현재완료(스페인에서는 최근·현재와 연결된 과거에 사용). `la última vez que...`: que는 관계사 역할.
- **시제:** `Veo` → ver, 직설법 현재 1인칭 단수 / `ha seguido` → seguir, 직설법 현재완료 3인칭 단수(usted) / `estudiando` → estudiar, 현재분사 / `hablamos` → hablar, 직설법 부정과거 1인칭 복수

### 7-14. **Álvaro:** Intento no quedarme atrás.

- **주요 단어:** `intentar` (동사) 시도하다 / `quedarse` (재귀동사) 남다, ~한 상태가 되다 / `atrás` (부사) 뒤에
- **문법:** `intentar + 동사원형`. 재귀대명사 `me`가 동사원형 뒤에 붙음(`quedarme`). 부정어 no는 동사원형 앞.
- **표현:** `quedarse atrás` = 뒤처지다.
- **시제:** `Intento` → intentar, 직설법 현재 1인칭 단수 / `quedarme` → quedarse, 동사원형

- **문법:** `poder + 동사원형`으로 허락을 구함.
