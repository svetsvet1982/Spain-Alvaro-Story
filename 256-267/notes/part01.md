## 장면 1. 페냐 알타 작전 제안
> 새로운 작전. 카를로스가 알바로에게 가장 무거운 국가안보급 사건을 제안합니다 — 가상의 원자력 발전소 '페냐 알타'에서 안전 시스템 설계도가 외부로 유출될 조짐이 포착됐습니다.

### 1-1. **Carlos:** Álvaro, este caso es distinto a todos los anteriores.
- **해석:** 알바로, 이번 사건은 이전의 모든 사건들과 달라.
- **주요 단어:** `caso` (명사, 남성) 사건 / `distinto` (형용사) 다른 / `anterior` (형용사) 이전의
- **문법:** `distinto a ~` "~와 다른" (`distinto de`도 가능). `los anteriores` 는 정관사 + 형용사로 명사(casos)를 생략한 명사화 용법. `este caso` 지시형용사 este + 남성 단수 명사.
- **표현:** 호칭 `Álvaro,` 로 시작하는 구어체. tú로 말하는 친근한 상사-요원 관계.
- **시제:** `es` → ser, 직설법 현재 3인칭 단수

### 1-2. **Carlos:** El nivel de riesgo es el más alto que te he pedido nunca.
- **해석:** 위험 수준이 내가 지금까지 너에게 부탁한 것 중 가장 높아.
- **주요 단어:** `nivel` (명사, 남성) 수준 / `riesgo` (명사, 남성) 위험 / `alto` (형용사) 높은 / `pedir` (동사) 부탁하다, 요청하다 / `nunca` (부사) 결코, (최상급 뒤에서) 지금까지
- **문법:** 최상급 `el más alto que ~` "~한 것 중 가장 높은". `que` 관계대명사. `te` 간접목적격 대명사(너에게)는 활용동사 앞. 최상급 뒤의 `nunca` 는 부정이 아니라 "여태껏/지금까지"의 의미(= jamás).
- **표현:** `el más ~ que + 현재완료 + nunca` "지금까지 ~한 것 중 가장 ~한" — 스페인식 최상급 강조 표현.
- **시제:** `es` → ser, 직설법 현재 3인칭 단수 / `he pedido` → pedir, 직설법 현재완료 1인칭 단수 (스페인에서는 "지금까지"의 경험을 현재완료로 표현)

### 1-3. **Álvaro:** Suena serio.
- **해석:** 심각하게 들리네요.
- **주요 단어:** `sonar` (동사) 소리가 나다, ~하게 들리다 / `serio` (형용사) 심각한, 진지한
- **문법:** `sonar + 형용사` "~하게 들리다". 주어(eso, 그 말)가 생략됨.
- **표현:** `Suena bien / serio / raro` 처럼 상대 말에 대한 반응으로 자주 쓰는 구어 표현.
- **시제:** `Suena` → sonar, 직설법 현재 3인칭 단수 (어간모음 변화 o→ue)

### 1-4. **Carlos:** Lo es.
- **해석:** 그래, 심각해.
- **주요 단어:** `lo` (중성 대명사) 그것(앞의 형용사를 받음)
- **문법:** 중성 대명사 `lo` 가 앞의 형용사 `serio` 를 대신함. ser/estar + 형용사를 반복하지 않고 `lo es / lo está` 로 받는 용법.
- **표현:** "Suena serio." — "Lo es." 는 "그렇게 들릴 뿐 아니라 실제로 그렇다"는 강조 응답.
- **시제:** `es` → ser, 직설법 현재 3인칭 단수

### 1-5. **Carlos:** La Central Nuclear de Peña Alta ha detectado accesos irregulares a los planos del sistema de seguridad del reactor.
- **해석:** 페냐 알타 원자력 발전소가 원자로 안전 시스템 설계도에 대한 비정상적인 접근을 감지했어.
- **주요 단어:** `central nuclear` (명사구, 여성) 원자력 발전소 / `detectar` (동사) 감지하다 / `acceso` (명사, 남성) 접근 / `irregular` (형용사) 비정상적인, 불규칙한 / `plano` (명사, 남성) 설계도, 도면 / `seguridad` (명사, 여성) 안전, 보안 / `reactor` (명사, 남성) 원자로
- **문법:** `acceso a ~` "~에 대한 접근" (전치사 a). `del` = de + el 축약(두 번). 명사 수식 구조 plano → sistema → reactor 연쇄.
- **시제:** `ha detectado` → detectar, 직설법 현재완료 3인칭 단수

- **문법:** 동사 생략된 선택 의문문. `desde + 부사` "~에서부터".
- **시제:** 동사 없음

- **문법:** 특이사항 없음 (동사 생략 응답)

### 1-8. **Carlos:** Alguien con acceso legítimo está copiando información que no debería salir de la instalación.
- **해석:** 정당한 접근 권한을 가진 누군가가 시설 밖으로 나가서는 안 되는 정보를 복사하고 있어.
- **주요 단어:** `alguien` (부정대명사) 누군가 / `legítimo` (형용사) 정당한, 합법적인 / `copiar` (동사) 복사하다 / `información` (명사, 여성) 정보 / `deber` (동사) ~해야 하다 / `salir` (동사) 나가다 / `instalación` (명사, 여성) 시설
- **문법:** `estar + 현재분사` 진행형. `que` 관계대명사(선행사 información). `deber + 부정사` 의무; 조건법 `debería` 로 "~해서는 안 될 텐데"라는 완곡/당위 표현. `salir de ~` "~에서 나가다".
- **시제:** `está copiando` → estar, 직설법 현재 3인칭 단수 + copiar 현재분사 (현재진행) / `debería` → deber, 가능법(조건법) 단순형 3인칭 단수 / `salir` → 부정사

### 1-9. **Álvaro:** ¿Sabemos para quién trabaja esa persona?
- **해석:** 그 사람이 누구를 위해 일하는지 알고 있나요?
- **주요 단어:** `saber` (동사) 알다 / `trabajar` (동사) 일하다 / `persona` (명사, 여성) 사람
- **문법:** 간접의문문 `para quién ~` (의문사 강세 유지). `trabajar para ~` "~를 위해 일하다". 지시형용사 `esa`.
- **시제:** `Sabemos` → saber, 직설법 현재 1인칭 복수 / `trabaja` → trabajar, 직설법 현재 3인칭 단수

### 1-11. **Carlos:** Podría ser un servicio de inteligencia extranjero, o un comprador dispuesto a pagar mucho por ese tipo de información en el mercado negro.
- **해석:** 외국 정보기관일 수도 있고, 암시장에서 그런 종류의 정보에 큰돈을 낼 의향이 있는 구매자일 수도 있어.
- **주요 단어:** `servicio de inteligencia` (명사구) 정보기관 / `extranjero` (형용사) 외국의 / `comprador` (명사, 남성) 구매자 / `dispuesto` (형용사, disponer의 과거분사) ~할 준비가 된 / `pagar` (동사) 지불하다 / `tipo` (명사, 남성) 종류 / `mercado negro` (명사구) 암시장
- **문법:** 조건법 `podría` 로 추측·가능성 표현. `dispuesto a + 부정사` "~할 의향이 있는". `pagar ... por ~` "~의 대가로 지불하다" (가격·대가의 por).
- **표현:** `pagar mucho` "큰돈을 내다". `mercado negro` 암시장.
- **시제:** `Podría` → poder, 가능법(조건법) 3인칭 단수 / `ser`, `pagar` → 부정사 / `dispuesto` → disponer 과거분사(형용사적 용법)

### 1-12. **Álvaro:** ¿Y qué necesitáis de mí exactamente?
- **해석:** 그럼 정확히 저한테서 뭘 필요로 하시는 거죠?
- **주요 단어:** `necesitar` (동사) 필요로 하다 / `exactamente` (부사) 정확히
- **문법:** 전치격 대명사 `mí` (전치사 de 뒤, 강세 있음). `necesitar algo de alguien` "누구에게서 ~을 필요로 하다".
- **표현:** `necesitáis` 는 vosotros 형 — 카를로스 개인이 아니라 "당신들(조직)"을 가리키는 스페인식 2인칭 복수.
- **시제:** `necesitáis` → necesitar, 직설법 현재 2인칭 복수 (vosotros)

### 1-13. **Carlos:** Que entres como consultor externo de ciberseguridad, contratado para auditar los sistemas de la central.
- **해석:** 발전소 시스템을 감사하도록 고용된 외부 사이버보안 컨설턴트로 들어가 줬으면 해.
- **주요 단어:** `entrar` (동사) 들어가다 / `consultor` (명사, 남성) 컨설턴트 / `externo` (형용사) 외부의 / `ciberseguridad` (명사, 여성) 사이버보안 / `contratar` (동사) 고용하다, 계약하다 / `auditar` (동사) 감사하다 / `central` (명사, 여성) 발전소
- **문법:** 앞 질문의 `necesitamos` 가 생략된 `(Necesitamos) que + 접속법` 구조 → `entres` 접속법. `como` "~로서". `contratado` 과거분사가 consultor를 수식(분사구). `para + 부정사` 목적.
- **표현:** 질문에 `Que + 접속법` 으로 바로 답하는 구어적 생략.
- **시제:** `entres` → entrar, 접속법 현재 2인칭 단수 / `contratado` → contratar, 과거분사 / `auditar` → 부정사

### 1-14. **Carlos:** Necesitamos identificar al topo antes de que complete la filtración.

- **문법:** `al topo` — 사람을 가리키는 직접목적어 앞 전치사 a (personal a) + el 축약. `antes de que + 접속법` (항상 접속법).
- **표현:** `topo` 는 스파이물에서 "내부 첩자"를 뜻하는 관용적 은유.
- **시제:** `Necesitamos` → necesitar, 직설법 현재 1인칭 복수 / `identificar` → 부정사 / `complete` → completar, 접속법 현재 3인칭 단수
