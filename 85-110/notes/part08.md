## 장면 13. 장관의 방문과 창의적 절충안
> 일주일 후, 스페인 문화부 장관이 잠시 참석해 협상에 대한 정부의 강력한 지지 의사를 표명합니다. 이후 오스카가 '소유권'과 '물리적 보관 장소'를 분리하는 창의적인 절충안을 제시하면서 교착 상태가 풀리기 시작합니다.

### 13-1. **Ministro:** (Entra brevemente) Señores, disculpen la interrupción.
- **해석:** (잠시 들어오며) 여러분, 중간에 끼어들어 죄송합니다.
- **주요 단어:** `entrar` (동사) 들어가다 / `brevemente` (부사) 잠깐, 짧게 / `señores` (명사, señor의 복수) 여러분, 신사분들 / `disculpar` (동사) 용서하다, 양해하다 / `la interrupción` (여성명사) 중단, 방해
- **문법:** `disculpen`은 ustedes에 대한 긍정 명령으로, 접속법 현재 3인칭 복수 형태를 사용함.
- **표현:** `Disculpen la interrupción` = "방해해서 죄송합니다". 회의 중에 들어갈 때 쓰는 정중한 관용 표현.
- **시제:** `Entra` → entrar, 직설법 현재 3인칭 단수(지문) / `disculpen` → disculpar, 명령법(접속법 현재) 3인칭 복수(ustedes)

### 13-2. **Ministro:** Solo quería decirles personalmente que este proceso tiene todo el respaldo del gobierno.
- **해석:** 이 과정이 정부의 전폭적인 지지를 받고 있다는 것을 직접 말씀드리고 싶었을 뿐입니다.
- **주요 단어:** `solo` (부사) 단지 / `querer` (동사) 원하다 / `decir` (동사) 말하다 / `personalmente` (부사) 직접, 개인적으로 / `el proceso` (남성명사) 과정 / `el respaldo` (남성명사) 지지, 후원 / `el gobierno` (남성명사) 정부
- **문법:** `quería`는 불완료과거로 현재의 바람을 공손하게 표현(완곡 용법). `decirles`: 간접목적대명사 les(=a ustedes)가 부정사 뒤에 붙음. `todo el respaldo` = 전폭적인 지지.
- **표현:** `Solo quería decirles que...` = "~라고 말씀드리려고 했을 뿐입니다". 공식 자리의 정중한 말투.
- **시제:** `quería` → querer, 직설법 불완료과거 1인칭 단수 / `decir` → 부정사 / `tiene` → tener, 직설법 현재 3인칭 단수

### 13-4. **Fernando:** Se lo agradecemos mucho.
- **해석:** 정말 감사드립니다.

- **문법:** 이중 목적대명사: 간접 `le`(=a usted)가 직접 `lo` 앞에서 `se`로 바뀜 → `se lo`. `lo`는 '그것(지지해 주신 것)'.
- **표현:** `Se lo agradezco/agradecemos (mucho)` = 매우 정중한 감사 표현.

- **시제:** `Confío` → confiar, 직설법 현재 1인칭 단수 / `encontrarán` → encontrar, 직설법 미래 3인칭 복수(ustedes)

- **문법:** `hay que + 부정사` = (일반적으로) ~해야 한다(무인칭 의무). `reconocerlo`: 대명사 lo가 부정사 뒤에 붙음(lo = 앞의 사실).
- **표현:** `hay que reconocerlo` = "그건 인정해야죠".
- **시제:** `hay` → haber, 직설법 현재 3인칭 단수(무인칭) / `reconocer` → 부정사

- **주요 단어:** `retomar` (동사) 다시 시작하다, 재개하다 / `dejar` (동사) 두다, 멈추다
- **문법:** `retomemos`: nosotros 청유 명령(접속법 현재 1인칭 복수). `donde`는 관계부사(장소). `dejamos`는 문맥상 과거(지난 세션).
- **표현:** `retomar donde lo dejamos` = "하던 데서 이어가다".
- **시제:** `retomemos` → retomar, 접속법 현재 1인칭 복수(청유 명령) / `dejamos` → dejar, 직설법 단순과거(점과거) 1인칭 복수

### 13-11. **Óscar:** He estado pensando en el caso del quipu, y creo que quizás estamos planteando el problema de forma equivocada.
- **해석:** 키푸 건에 대해 계속 생각해 봤는데, 어쩌면 우리가 문제를 잘못된 방식으로 접근하고 있는 것 같습니다.
- **주요 단어:** `pensar en` (동사구) ~에 대해 생각하다 / `el caso` (남성명사) 사례, 건 / `el quipu` (남성명사) 키푸(잉카의 매듭 기록 도구) / `creer` (동사) 생각하다, 믿다 / `quizás` (부사) 아마 / `plantear` (동사) (문제를) 제기하다, 설정하다 / `de forma equivocada` (부사구) 잘못된 방식으로
- **문법:** `He estado pensando` = 현재완료 진행형(haber + estado + 현재분사): 과거부터 지금까지 계속된 동작. `estamos planteando` = 현재진행형. `creo que` + 직설법. `de forma + 형용사` = ~한 방식으로(부사 역할).
- **시제:** `He estado` → estar, 직설법 현재완료 1인칭 단수 + `pensando` → pensar 현재분사 / `creo` → creer, 직설법 현재 1인칭 단수 / `estamos` → estar, 직설법 현재 1인칭 복수 + `planteando` → plantear 현재분사

### 13-13. **Óscar:** ¿Qué les parecería separar dos cosas que hemos estado tratando como una sola: la titularidad legal de la pieza, y su ubicación física?
- **해석:** 우리가 하나로 다뤄 온 두 가지, 즉 유물의 법적 소유권과 그 물리적 위치를 분리하는 건 어떻게 생각하십니까?
- **주요 단어:** `parecer` (동사) ~처럼 보이다, ~라고 생각되다 / `separar` (동사) 분리하다 / `tratar` (동사) 다루다 / `la titularidad` (여성명사) 소유권, 명의 / `legal` (형용사) 법적인 / `la pieza` (여성명사) (유물·작품) 한 점 / `la ubicación` (여성명사) 위치 / `físico` (형용사) 물리적인
- **문법:** `¿Qué les parecería + 부정사?` = gustar형 동사 parecer + 간접목적대명사 les. 조건법으로 제안을 부드럽게 함. `que`는 관계대명사(선행사 dos cosas). `como una sola` = 하나인 것처럼. 콜론(:) 뒤에 두 가지를 구체적으로 나열.
- **표현:** `¿Qué le(s) parece/parecería...?` = "~은 어떠세요?" (제안·의견 묻기).
- **시제:** `parecería` → parecer, 조건법(가능법) 3인칭 단수 / `separar` → 부정사 / `hemos estado` → estar, 직설법 현재완료 1인칭 복수 + `tratando` → tratar 현재분사

### 14-39. **Óscar:** Aunque, si le soy sincero, prefiero las negociaciones a las persecuciones a medianoche.

- **시제:** `soy` → ser, 직설법 현재 1인칭 단수 / `prefiero` → preferir, 직설법 현재 1인칭 단수(e→ie)
