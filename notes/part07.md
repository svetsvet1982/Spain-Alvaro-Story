## 장면 11. 합동 실무위원회: 유물별 사례 검토
> 한 달 후, 스페인-페루 합동 실무위원회 회의가 열립니다. 명단에 오른 구체적 유물 사례들을 하나씩 검토하며, 이번엔 훨씬 날카로운 반박과 재반박이 오갑니다.

### 11-1. **Fernando:** Bien, empecemos con el primer caso de la lista: el manto paracas catalogado como pieza siete.
- **해석:** 좋습니다, 목록의 첫 번째 사례부터 시작합시다. 7번 유물로 분류된 파라카스 망토입니다.
- **주요 단어:** `empezar` (동사) 시작하다 / `caso` (명사, m.) 사례, 건 / `lista` (명사, f.) 목록, 명단 / `manto` (명사, m.) 망토, 직물 덮개 / `paracas` (고유명사·형용사적) 파라카스(페루 남부 해안의 고대 문화, 직물로 유명) / `catalogar` (동사) 목록에 올리다, 분류하다 / `pieza` (명사, f.) (소장품·유물의) 점, 작품
- **문법:** `empecemos`는 nosotros에 대한 권유("~합시다")로 접속법 현재 1인칭 복수를 사용. `empezar con` ~로 시작하다. `catalogado`는 과거분사가 형용사처럼 명사 `manto`를 수식(성·수 일치: 남성 단수). 콜론(:) 뒤에 구체적 내용을 제시.
- **표현:** `Bien, ...` 회의 진행자가 본론으로 들어갈 때 쓰는 말("자, 그럼"). `pieza siete` 번호를 뒤에 붙이는 방식 = "7번 유물".
- **시제:** `empecemos` → empezar, 접속법 현재 1인칭 복수(권유 명령) / `catalogado` → catalogar, 과거분사(남성 단수)

### 11-2. **Alonso:** Según nuestros archivos, esa pieza fue exportada en 1978 sin el permiso correspondiente del Instituto Nacional de Cultura.
- **해석:** 저희 기록 보관 자료에 따르면, 그 유물은 1978년에 국립문화연구소의 정식 허가 없이 반출되었습니다.
- **주요 단어:** `según` (전치사) ~에 따르면 / `archivo` (명사, m.) 기록, 문서 보관소 / `exportar` (동사) 수출하다, 반출하다 / `permiso` (명사, m.) 허가 / `correspondiente` (형용사) 해당하는, 그에 맞는 / `Instituto Nacional de Cultura` 국립문화연구소(페루의 옛 문화 담당 기관)
- **문법:** `fue exportada` = ser + 과거분사의 수동태(단순과거). 과거분사는 주어 `esa pieza`(여성 단수)에 일치하여 `exportada`. `sin` + 명사 = ~ 없이.
- **표현:** `el permiso correspondiente` "필요한(해당) 허가", 행정·법률 문서에서 자주 쓰는 표현.
- **시제:** `fue` → ser, 직설법 단순과거(부정과거) 3인칭 단수 / `exportada` → exportar, 과거분사(여성 단수)

### 11-3. **Mariano:** Discrepo respetuosamente con esa conclusión.
- **해석:** 외람되지만 그 결론에는 동의하지 않습니다.
- **주요 단어:** `discrepar` (동사) 의견이 다르다, 이견이 있다 / `respetuosamente` (부사) 정중하게 / `conclusión` (명사, f.) 결론
- **문법:** `discrepar con/de` + 명사 = ~와 의견을 달리하다. 형용사 `respetuoso`의 여성형 + `-mente`로 부사 형성.
- **표현:** 공식 회의에서 반대 의견을 정중하게 표명하는 전형적 표현. "No estoy de acuerdo"보다 격식 있음.
- **시제:** `discrepo` → discrepar, 직설법 현재 1인칭 단수

### 11-4. **Mariano:** Tenemos un certificado de exportación fechado ese mismo año, firmado por un funcionario del propio instituto.
- **해석:** 저희에게는 바로 그해 날짜가 적힌 수출 증명서가 있고, 그 연구소 소속 공무원이 직접 서명한 것입니다.
- **주요 단어:** `certificado` (명사, m.) 증명서 / `exportación` (명사, f.) 수출, 반출 / `fechar` (동사) 날짜를 기입하다 / `firmar` (동사) 서명하다 / `funcionario` (명사, m.) 공무원 / `propio` (형용사) 바로 그, 자신의
- **문법:** `fechado`, `firmado`는 과거분사가 형용사처럼 `certificado`를 수식. `firmado por` ~에 의해 서명된(행위자 por). `ese mismo año` "바로 그 해". `propio`가 명사 앞에 오면 "바로 그 (기관) 자체의"라는 강조.
- **표현:** `del propio instituto` "다름 아닌 그 연구소의" — 상대 측 기관이 발행한 것임을 강조.
- **시제:** `tenemos` → tener, 직설법 현재 1인칭 복수 / `fechado` → fechar, 과거분사 / `firmado` → firmar, 과거분사

### 11-5. **Alonso:** Ese funcionario fue destituido dos años después por corrupción, precisamente por emitir certificados irregulares.
- **해석:** 그 공무원은 2년 뒤 부패 혐의로 파면되었습니다. 바로 부정한 증명서를 발급했다는 이유로요.
- **주요 단어:** `destituir` (동사) 파면하다, 해임하다 / `corrupción` (명사, f.) 부패 / `precisamente` (부사) 바로, 정확히 / `emitir` (동사) 발급하다, 발행하다 / `irregular` (형용사) 부정한, 규정에 어긋난
- **문법:** `fue destituido` = ser 수동태(단순과거). `por` + 명사/동사원형 = 원인·이유("~때문에"). `dos años después` "2년 후".
- **표현:** `precisamente por...` "하필이면 바로 ~때문에" — 상대 논거를 정면으로 무력화하는 강조.
- **시제:** `fue` → ser, 직설법 단순과거 3인칭 단수 / `destituido` → destituir, 과거분사 / `emitir` → 동사원형(전치사 por 뒤)

### 11-6. **Mariano:** Eso no invalida automáticamente el documento en el momento en que se emitió.
- **해석:** 그렇다고 해서 발급된 시점의 그 문서가 자동으로 무효가 되는 건 아닙니다.
- **주요 단어:** `invalidar` (동사) 무효로 하다 / `automáticamente` (부사) 자동으로 / `documento` (명사, m.) 문서 / `momento` (명사, m.) 시점, 순간 / `emitir` 앞에서 설명
- **문법:** `en el momento en que` + 직설법 = "~한 시점에"(관계사 que 앞에 전치사 en 반복). `se emitió`는 수동의 se(비인칭 수동: "발급되었다").
- **표현:** 법적 논리에서 "당시 기준으로 유효"를 주장하는 논법.
- **시제:** `invalida` → invalidar, 직설법 현재 3인칭 단수 / `emitió` → emitir, 직설법 단순과거 3인칭 단수(수동 se)

### 11-7. **Mariano:** Era válido según los procedimientos vigentes entonces.
- **해석:** 당시 시행되던 절차에 따르면 그것은 유효했습니다.
- **주요 단어:** `válido` (형용사) 유효한 / `procedimiento` (명사, m.) 절차 / `vigente` (형용사) 현행의, 효력이 있는 / `entonces` (부사) 그 당시에
- **문법:** 과거의 지속적 상태 묘사이므로 불완료과거 `era`. ser + 형용사(válido)로 본질적 성격을 판단. `vigentes entonces` "그 당시 유효했던".
- **표현:** `vigente` 법·규정 관련 핵심 어휘("현행법" = ley vigente).
- **시제:** `era` → ser, 직설법 불완료과거 3인칭 단수

### 11-8. **Óscar:** Si me permite matizar, Mariano, el hecho de que el procedimiento fuera formalmente correcto no significa que el resultado lo fuera.
- **해석:** 한 가지 보충하자면, 마리아노 씨, 절차가 형식적으로 올바랐다는 사실이 결과도 올바랐다는 뜻은 아닙니다.
- **주요 단어:** `permitir` (동사) 허락하다 / `matizar` (동사) 뉘앙스를 더하다, 세밀하게 구분하다 / `hecho` (명사, m.) 사실 / `formalmente` (부사) 형식적으로 / `correcto` (형용사) 올바른 / `significar` (동사) 의미하다 / `resultado` (명사, m.) 결과
- **문법:** `si` + 직설법 현재(조건). `el hecho de que` + 접속법 → `fuera`(접속법 불완료과거). `no significa que` + 접속법(부정된 판단 동사) → `lo fuera`. `lo`는 앞의 형용사 `correcto`를 대신하는 중성 대명사(ser/estar의 보어를 받음).
- **표현:** `Si me permite matizar` "조금 덧붙여 구분하자면" — 상대 말을 정중하게 수정할 때 쓰는 격식 표현(usted).
- **시제:** `permite` → permitir, 직설법 현재 3인칭 단수(usted) / `matizar` → 동사원형 / `fuera` → ser, 접속법 불완료과거 3인칭 단수 / `significa` → significar, 직설법 현재 3인칭 단수 / `fuera` → ser, 접속법 불완료과거 3인칭 단수

### 11-9. **Óscar:** Ahí hay una diferencia importante.
- **해석:** 거기에 중요한 차이가 있습니다.
- **주요 단어:** `ahí` (부사) 거기에, 그 점에 / `diferencia` (명사, f.) 차이
- **문법:** `hay` = haber의 비인칭 존재 표현("~이 있다").
- **표현:** `ahí` 는 장소뿐 아니라 "그 점에서"라는 논리적 지점을 가리킴.
- **시제:** `hay` → haber, 직설법 현재 3인칭 단수(비인칭)

### 11-10. **Mariano:** Entiendo la distinción, pero no podemos anular retroactivamente documentos oficiales solo porque después se descubrió que quien los firmó era corrupto.
- **해석:** 그 구분은 이해합니다만, 나중에 서명한 사람이 부패했다고 밝혀졌다는 이유만으로 공문서를 소급해서 무효화할 수는 없습니다.
- **주요 단어:** `entender` (동사) 이해하다 / `distinción` (명사, f.) 구분 / `anular` (동사) 취소하다, 무효화하다 / `retroactivamente` (부사) 소급하여 / `oficial` (형용사) 공식의 / `descubrir` (동사) 발견하다, 밝혀내다 / `corrupto` (형용사) 부패한
- **문법:** `poder` + 동사원형. `solo porque` "단지 ~라는 이유로". `se descubrió` 수동의 se. `quien los firmó` 선행사를 포함한 관계대명사 quien("서명한 사람"), `los` = documentos(직접목적 대명사, 동사 앞). `era corrupto` 과거 상태 → 불완료과거.
- **표현:** `Entiendo..., pero...` 상대 논거를 인정한 뒤 반박하는 협상 화법.
- **시제:** `entiendo` → entender, 직설법 현재 1인칭 단수 / `podemos` → poder, 직설법 현재 1인칭 복수 / `anular` → 동사원형 / `descubrió` → descubrir, 직설법 단순과거 3인칭 단수 / `firmó` → firmar, 직설법 단순과거 3인칭 단수 / `era` → ser, 직설법 불완료과거 3인칭 단수

### 11-11. **Alonso:** Con todo respeto, eso es exactamente lo que deberíamos poder hacer cuando hay pruebas de que el documento se obtuvo de forma fraudulenta.
- **해석:** 외람되지만, 그 문서가 사기적으로 취득되었다는 증거가 있을 때 바로 그렇게 할 수 있어야 한다는 겁니다.
- **주요 단어:** `respeto` (명사, m.) 존중 / `exactamente` (부사) 정확히 / `prueba` (명사, f.) 증거 / `obtener` (동사) 얻다, 취득하다 / `forma` (명사, f.) 방식 / `fraudulento` (형용사) 사기의, 부정한
- **문법:** `lo que` 중성 관계사("~하는 것"). `deberíamos poder hacer` = deber(조건법) + poder + hacer, 동사원형 연쇄("할 수 있어야 할 것이다"). `pruebas de que` + 직설법(사실 내용). `se obtuvo` 수동의 se. `de forma` + 형용사 = 부사구("~한 방식으로").
- **표현:** `Con todo respeto` "외람되지만, 실례지만" — 강한 반박 앞의 완충 표현. 조건법 `deberíamos`로 주장을 부드럽게.
- **시제:** `es` → ser, 직설법 현재 3인칭 단수 / `deberíamos` → deber, 조건법 현재 1인칭 복수 / `poder`, `hacer` → 동사원형 / `hay` → haber, 직설법 현재(비인칭) / `obtuvo` → obtener, 직설법 단순과거 3인칭 단수(불규칙)

### 11-12. **Fernando:** Alonso tiene un punto válido ahí, Mariano.
- **해석:** 마리아노 씨, 그 점에서는 알론소 씨 말에도 일리가 있습니다.
- **주요 단어:** `punto` (명사, m.) 요점, 논점 / `válido` 앞에서 설명
- **문법:** 특이사항 없음
- **표현:** `tener un punto (válido)` "일리가 있다"(영어 have a point에서 온 표현, 구어·회의에서 흔함).
- **시제:** `tiene` → tener, 직설법 현재 3인칭 단수

### 11-13. **Fernando:** Si el origen del permiso está viciado, el permiso mismo pierde legitimidad.
- **해석:** 허가의 출처에 하자가 있다면, 그 허가 자체가 정당성을 잃게 됩니다.
- **주요 단어:** `origen` (명사, m.) 출처, 기원 / `viciar` (동사) 하자를 만들다, 훼손하다 / `mismo` (형용사) ~자체 / `perder` (동사) 잃다 / `legitimidad` (명사, f.) 정당성, 합법성
- **문법:** `si` + 직설법 현재, 주절 직설법 현재(일반적 조건). `estar` + 과거분사(`viciado`) = 결과 상태. 명사 뒤 `mismo` = "그 자체".
- **표현:** `estar viciado` 법률 용어로 "(절차·계약이) 하자가 있다".
- **시제:** `está` → estar, 직설법 현재 3인칭 단수 / `viciado` → viciar, 과거분사 / `pierde` → perder, 직설법 현재 3인칭 단수(e→ie 어간변화)

### 11-14. **Mariano:** Comprendo el argumento, pero eso abre la puerta a cuestionar cualquier documento de esa época, y necesitamos límites claros, o esto no va a terminar nunca.
- **해석:** 논지는 이해합니다만, 그렇게 되면 그 시대의 어떤 문서든 문제 삼을 수 있는 길이 열리게 됩니다. 명확한 한계가 필요합니다. 그렇지 않으면 이 일은 절대 끝나지 않을 겁니다.
- **주요 단어:** `comprender` (동사) 이해하다 / `argumento` (명사, m.) 논거 / `abrir` (동사) 열다 / `cuestionar` (동사) 이의를 제기하다 / `cualquier` (형용사) 어떤 ~라도 / `época` (명사, f.) 시대 / `límite` (명사, m.) 한계, 경계 / `terminar` (동사) 끝나다
- **문법:** `abrir la puerta a` + 동사원형/명사. `cualquier`는 명사 앞에서 어미 탈락. `ir a` + 동사원형 = 가까운 미래. `no ... nunca` 이중부정. `o` "그렇지 않으면".
- **표현:** `abrir la puerta a algo` "~의 여지를 열다"(관용구). `esto no va a terminar nunca` 끝이 없다는 불만 표현.
- **시제:** `comprendo` → comprender, 직설법 현재 1인칭 단수 / `abre` → abrir, 직설법 현재 3인칭 단수 / `cuestionar` → 동사원형 / `necesitamos` → necesitar, 직설법 현재 1인칭 복수 / `va` → ir, 직설법 현재 3인칭 단수 / `terminar` → 동사원형
