## 장면 4. 수상한 출입 기록
> 알바로가 사무실에서 지난 몇 주간의 출입 기록을 살펴보며, 의심스러운 패턴을 발견하기 시작합니다.

### 4-1. **Álvaro:** (Revisando registros) Interesante.
- **해석:** (기록을 검토하며) 흥미롭군요.
- **주요 단어:** `revisar` (동사) 검토하다, 점검하다 / `registro` (남성 명사) 기록, 로그 / `interesante` (형용사) 흥미로운
- **문법:** 지문의 `revisando`는 현재분사(gerundio)로 동시 동작("~하면서")을 나타냄. 본문은 `Es interesante`에서 동사가 생략된 감탄형 한 단어 문장.
- **표현:** `Interesante.` 한 단어로 뭔가 눈에 띄었다는 뉘앙스를 줌. 수사물에서 자주 쓰는 반응.
- **시제:** `Revisando` → revisar, 현재분사(gerundio)

### 4-2. **Álvaro:** Alguien ha accedido a la sala de planos técnicos fuera de horario, cuatro veces en las últimas tres semanas.
- **해석:** 누군가 근무 시간 외에 기술 도면실에 접근했어요. 최근 3주 동안 네 번이나요.
- **주요 단어:** `alguien` (부정대명사) 누군가 / `acceder` (동사) 접근하다, 출입하다 / `sala` (여성 명사) 방, 실 / `plano` (남성 명사) 도면, 설계도 / `técnico` (형용사) 기술적인 / `fuera de` (전치사구) ~ 밖에 / `horario` (남성 명사) 근무 시간, 시간표 / `vez` (여성 명사, 복수 veces) 번, 회
- **문법:** 현재완료(`ha accedido`) — 스페인 스페인어에서는 최근·현재와 연결된 기간(`en las últimas tres semanas`) 안의 사건에 현재완료를 씀. `acceder a` + 장소: '~에 접근하다'(전치사 a 필수). `últimas`는 명사 앞에 와서 '최근의'라는 뜻.
- **표현:** `fuera de horario` = 업무 시간 외. `cuatro veces` = 네 번.
- **시제:** `ha accedido` → acceder, 직설법 현재완료 3인칭 단수

### 4-3. **Mauricio:** ¿Quién?
- **해석:** 누구죠?
- **주요 단어:** `quién` (의문대명사) 누구
- **문법:** 의문사에는 강세 부호(tilde)가 붙음: `quién`. 동사가 생략된 의문문.
- **시제:** 동사 없음

### 4-4. **Álvaro:** El registro solo muestra el número de credencial, no el nombre.
- **해석:** 기록에는 출입증 번호만 나오고, 이름은 안 나와요.
- **주요 단어:** `registro` 앞에서 설명 / `solo` (부사) 단지, ~만 / `mostrar` (동사) 보여주다 / `número` (남성 명사) 번호 / `credencial` (여성 명사) 출입증, 신분증 / `nombre` (남성 명사) 이름
- **문법:** `mostrar`는 어간모음 변화 동사(o → ue): `muestra`. `solo ..., no ...` 구조로 대조를 표현.
- **표현:** `número de credencial` = 사원증/출입증 번호.
- **시제:** `muestra` → mostrar, 직설법 현재 3인칭 단수

### 4-5. **Álvaro:** ¿Puede identificarlo?
- **해석:** (그 사람이 누군지) 확인해 주실 수 있나요?
- **주요 단어:** `poder` (동사) ~할 수 있다 / `identificar` (동사) 신원을 확인하다, 식별하다
- **문법:** 직접목적격 대명사 `lo`가 부정사 뒤에 붙음(`identificarlo`). `Lo puede identificar`로도 가능. `lo`는 앞 문장의 '번호/그 사람'을 가리킴. usted(존칭) 3인칭 형태 사용.
- **표현:** `¿Puede + 부정사?` = 존댓말 공손한 요청.
- **시제:** `Puede` → poder, 직설법 현재 3인칭 단수(usted) / `identificar` → 부정사

### 4-6. **Mauricio:** (Consulta el sistema) Credencial cero-cuatro-siete.
- **해석:** (시스템을 조회하며) 출입증 047번이네요.
- **주요 단어:** `consultar` (동사) 조회하다, 참고하다 / `sistema` (남성 명사, -a로 끝나지만 남성) 시스템 / `cero` 0 / `cuatro` 4 / `siete` 7
- **문법:** `sistema`는 그리스어 기원의 -ma 명사로 남성(`el sistema`). 본문은 동사 없는 명사구.
- **표현:** 번호를 숫자 하나씩 읽음(cero-cuatro-siete).
- **시제:** `Consulta` → consultar, 직설법 현재 3인칭 단수(지문)

### 4-7. **Mauricio:** Corresponde a Elena Ferrer, ingeniera de sistemas de seguridad.
- **해석:** 엘레나 페레르 거네요. 보안 시스템 엔지니어예요.
- **주요 단어:** `corresponder` (동사) 해당하다, ~의 것이다 / `ingeniera` (여성 명사, 남성 ingeniero) 엔지니어 / `seguridad` (여성 명사) 보안, 안전
- **문법:** `corresponder a` + 사람: '~에게 해당하다'. `ingeniera de sistemas de seguridad`는 동격 설명(쉼표로 연결), 직업 앞에 관사 없음.
- **시제:** `Corresponde` → corresponder, 직설법 현재 3인칭 단수

### 4-8. **Álvaro:** ¿Es habitual que ella acceda fuera de horario?
- **해석:** 그녀가 근무 시간 외에 출입하는 게 흔한 일인가요?
- **주요 단어:** `habitual` (형용사) 평소의, 흔한 / `acceder` 앞에서 설명
- **문법:** `Es + 형용사 + que + 접속법` 비인칭 구문: 평가·판단 표현 뒤 que절은 접속법. `acceda`는 acceder의 접속법 현재.
- **표현:** `¿Es habitual que...?` = ~하는 게 보통인가요?
- **시제:** `Es` → ser, 직설법 현재 3인칭 단수 / `acceda` → acceder, 접속법 현재 3인칭 단수

### 4-9. **Mauricio:** No especialmente.
- **해석:** 딱히 그렇진 않아요.
- **주요 단어:** `especialmente` (부사) 특별히
- **문법:** 특이사항 없음
- **표현:** `No especialmente` = "특별히 그렇진 않다", 완곡한 부정.
- **시제:** 동사 없음

### 4-10. **Mauricio:** Aunque a veces el personal se queda hasta tarde por proyectos concretos.
- **해석:** 그래도 가끔 직원들이 특정 프로젝트 때문에 늦게까지 남기도 해요.
- **주요 단어:** `aunque` (접속사) 비록 ~지만, 그래도 / `a veces` 가끔 / `personal` (남성 명사) 직원, 인원 / `quedarse` (재귀동사) 남다, 머무르다 / `tarde` (부사) 늦게 / `proyecto` (남성 명사) 프로젝트 / `concreto` (형용사) 구체적인, 특정한
- **문법:** 재귀동사 `quedarse`: `se queda`. `el personal`은 집합명사라 3인칭 단수로 받음. `por` = 원인·이유("~ 때문에"). `aunque` + 직설법 = 사실에 대한 양보.
- **표현:** `quedarse hasta tarde` = 늦게까지 남다(야근하다).
- **시제:** `se queda` → quedarse, 직설법 현재 3인칭 단수

### 4-11. **Álvaro:** ¿Sabe en qué proyecto está trabajando actualmente?
- **해석:** 그녀가 요즘 어떤 프로젝트를 하고 있는지 아세요?
- **주요 단어:** `saber` (동사) 알다 / `trabajar` (동사) 일하다 / `actualmente` (부사) 현재, 요즘 (영어 actually 아님!)
- **문법:** 간접의문문 `en qué proyecto` — 의문사 강세 유지. `estar + 현재분사` 진행형. `trabajar en` + 프로젝트 → 전치사 en이 의문사 앞에 옴.
- **표현:** `actualmente`는 '현재'라는 뜻의 false friend.
- **시제:** `Sabe` → saber, 직설법 현재 3인칭 단수(usted) / `está trabajando` → estar + trabajar, 직설법 현재진행 3인칭 단수

### 4-12. **Mauricio:** Creo que en la actualización del sistema de refrigeración de emergencia, precisamente.
- **해석:** 제 생각엔, 바로 그 비상 냉각 시스템 업데이트를 하고 있을 거예요.
- **주요 단어:** `creer` (동사) 믿다, 생각하다 / `actualización` (여성 명사) 업데이트, 갱신 / `refrigeración` (여성 명사) 냉각 / `emergencia` (여성 명사) 비상 / `precisamente` (부사) 바로, 정확히
- **문법:** `Creo que` + 직설법(긍정 의견). que절에서 동사(`está trabajando`)가 생략됨. `del` = de + el 축약.
- **표현:** `precisamente` = "하필이면 바로 그것"이라는 강조 뉘앙스(알바로가 의심하는 시스템이라서).
- **시제:** `Creo` → creer, 직설법 현재 1인칭 단수

### 4-13. **Álvaro:** (Alerta, disimulando) Eso explicaría el acceso frecuente a esos planos concretos.
- **해석:** (경계하면서도 티 내지 않으며) 그렇다면 그 특정 도면들에 자주 접근한 게 설명되겠네요.
- **주요 단어:** `alerta` (형용사/부사) 경계하는 / `disimular` (동사) 숨기다, 모른 척하다 / `explicar` (동사) 설명하다 / `acceso` (남성 명사) 접근, 출입 / `frecuente` (형용사) 잦은 / `concreto` 앞에서 설명
- **문법:** 가능법(condicional) `explicaría` — 추측·가정("그렇다면 ~이겠다"). 지시사 `eso`(중성, 앞 내용 전체), `esos`(지시형용사 남성 복수).
- **표현:** `disimulando` = 속마음을 감추며.
- **시제:** `disimulando` → disimular, 현재분사 / `explicaría` → explicar, 직설법 가능법(조건법) 3인칭 단수

### 4-14. **Mauricio:** Sí, tiene sentido dentro de su trabajo normal.
- **해석:** 네, 평소 업무 범위 안에서는 말이 되죠.
- **주요 단어:** `tener` (동사) 가지다 / `sentido` (남성 명사) 의미, 감각 / `dentro de` ~ 안에서 / `normal` (형용사) 평소의
- **문법:** 특이사항 없음
- **표현:** `tener sentido` = 말이 되다, 이치에 맞다.
- **시제:** `tiene` → tener, 직설법 현재 3인칭 단수

### 4-15. **Álvaro:** Aun así, me gustaría hablar con ella, como parte de la auditoría rutinaria de todo el personal con acceso de nivel tres.
- **해석:** 그래도 레벨 3 출입 권한을 가진 전 직원 대상의 정기 감사의 일환으로 그녀와 얘기해 보고 싶어요.
- **주요 단어:** `aun así` 그렇다 하더라도 / `gustar` (동사) 마음에 들다 / `hablar` (동사) 말하다 / `como parte de` ~의 일환으로 / `auditoría` (여성 명사) 감사 / `rutinario` (형용사) 정기적인, 일상적인 / `nivel` (남성 명사) 등급, 레벨
- **문법:** `me gustaría` + 부정사 = 공손한 희망(가능법). `gustar`형 동사: 간접목적어 `me`. `con ella` 전치사 뒤 주격형 대명사. `aun`(강세 없음) = incluso(~조차).
- **표현:** `Aun así` = "그렇긴 해도". `me gustaría` = quiero보다 정중.
- **시제:** `gustaría` → gustar, 직설법 가능법 3인칭 단수 / `hablar` → 부정사

### 4-16. **Mauricio:** Puedo organizarlo para mañana.
- **해석:** 내일로 잡아 드릴 수 있어요.
- **주요 단어:** `poder` 앞에서 설명 / `organizar` (동사) 준비하다, 마련하다 / `mañana` (부사) 내일
- **문법:** `organizarlo` — 목적격 대명사 lo가 부정사 뒤에 붙음(= la reunión/el encuentro, 중성적으로 '그 일'). `para` + 시점 = 기한·예정.
- **시제:** `Puedo` → poder, 직설법 현재 1인칭 단수 / `organizar` → 부정사

## 장면 5. 엘레나와의 인터뷰
> 다음 날, 알바로가 엘레나 페레르를 보안 감사 명목으로 인터뷰합니다.

### 5-1. **Elena:** (Algo tensa) Mauricio me dijo que necesitaba hablar conmigo, como parte de la auditoría.
- **해석:** (약간 긴장한 채) 마우리시오가 감사의 일환으로 저와 얘기하셔야 한다고 하더군요.
- **주요 단어:** `algo` (부사) 약간 / `tenso` (형용사) 긴장한 / `decir` (동사) 말하다 / `necesitar` (동사) 필요하다 / `conmigo` 나와 함께
- **문법:** 부정과거(`dijo`)로 완결된 과거 발화, 전달된 내용(간접화법)에서는 불완료과거(`necesitaba`)로 시제 일치. `conmigo` = con + mí의 특수형. `me`는 간접목적격(나에게).
- **표현:** `algo tensa` — `algo`가 형용사 앞에서 '좀, 약간'.
- **시제:** `dijo` → decir, 직설법 부정과거(단순과거) 3인칭 단수 / `necesitaba` → necesitar, 직설법 불완료과거 3인칭 단수(usted) / `hablar` → 부정사

### 5-2. **Álvaro:** Así es, es un procedimiento rutinario para todo el personal con acceso de nivel tres.
- **해석:** 맞아요, 레벨 3 출입 권한을 가진 모든 직원에게 하는 정기 절차예요.
- **주요 단어:** `así` (부사) 그렇게 / `procedimiento` (남성 명사) 절차 / `rutinario`, `personal`, `acceso`, `nivel` 앞에서 설명
- **문법:** `ser` + 명사(정체·분류). `para` = 대상.
- **표현:** `Así es` = "그렇습니다, 맞아요".
- **시제:** `es` (2회) → ser, 직설법 현재 3인칭 단수

### 5-3. **Álvaro:** Nada personal.
- **해석:** 개인적인 건 아니에요.
- **주요 단어:** `nada` (부정대명사) 아무것도 ~않다 / `personal` (형용사) 개인적인
- **문법:** 동사 생략(`No es nada personal`). 여기의 `personal`은 형용사(앞 문장의 명사 '직원'과 구별).
- **표현:** `Nada personal` = "악의는 없어요/개인적인 감정 아니에요".
- **시제:** 동사 없음

### 5-4. **Elena:** Entiendo.
- **해석:** 알겠습니다.
- **주요 단어:** `entender` (동사) 이해하다
- **문법:** 어간모음 변화 동사(e → ie).
- **표현:** 대화에서 "알겠어요"로 흔히 사용.
- **시제:** `Entiendo` → entender, 직설법 현재 1인칭 단수

### 5-5. **Elena:** ¿Qué necesita saber?
- **해석:** 뭘 알고 싶으세요?
- **주요 단어:** `necesitar`, `saber` 앞에서 설명
- **문법:** `necesitar` + 부정사 = ~할 필요가 있다. usted 존칭.
- **시제:** `necesita` → necesitar, 직설법 현재 3인칭 단수(usted) / `saber` → 부정사

### 5-6. **Álvaro:** Su trabajo reciente en el sistema de refrigeración de emergencia.
- **해석:** 비상 냉각 시스템과 관련해 최근 하신 업무요.

### 5-7. **Álvaro:** ¿Podría explicarme en qué consiste exactamente?
- **해석:** 정확히 어떤 일인지 설명해 주시겠어요?
- **주요 단어:** `explicar` 앞에서 설명 / `consistir` (동사) ~로 이루어지다 / `exactamente` (부사) 정확히

- **표현:** `Tengo algo` = "뭔가 찾았어".
- **시제:** `llama` → llamar, 직설법 현재 3인칭 단수 / `tengo` → tener, 직설법 현재 1인칭 단수

### 6-13. **Carlos:** Elena tiene deudas considerables, y hace tres meses recibió una transferencia de origen poco claro.
- **해석:** 엘레나는 빚이 상당하고, 석 달 전에 출처가 불분명한 송금을 받았어.
- **주요 단어:** `deuda` (여성 명사) 빚 / `considerable` (형용사) 상당한 / `recibir` (동사) 받다 / `transferencia` (여성 명사) 계좌이체, 송금 / `origen` (남성 명사) 출처 / `poco claro` 불분명한
- **문법:** `hace + 기간` = ~ 전에(과거 시점) → 부정과거와 함께. `poco` + 형용사 = 별로 ~하지 않은. `claro`는 `origen`(남성)에 일치.
- **표현:** `de origen poco claro` = 출처가 수상한.
- **시제:** `tiene` → tener, 직설법 현재 3인칭 단수 / `hace` → hacer, 직설법 현재 3인칭 단수(비인칭 시간 표현) / `recibió` → recibir, 직설법 부정과거 3인칭 단수

### 6-14. **Álvaro:** ¿Cuánto?

### 6-15. **Carlos:** Quince mil euros, desde una cuenta en un paraíso fiscal.
- **해석:** 1만 5천 유로야, 조세 피난처에 있는 계좌에서.
- **주요 단어:** `quince mil` 15,000 / `desde` (전치사) ~에서부터 / `cuenta` (여성 명사) 계좌 / `paraíso fiscal` (남성 명사구) 조세 피난처
- **문법:** `mil`은 복수형 없음(quince mil). `desde` = 출발점.
- **표현:** `paraíso fiscal` = 조세 피난처(직역: 세금 천국).
- **시제:** 동사 없음

### 6-16. **Álvaro:** Eso ya no es coincidencia.
- **해석:** 그건 이제 우연이 아니네요.

### 6-17. **Carlos:** No lo es.

- **시제:** `es` → ser, 직설법 현재 3인칭 단수

### 6-18. **Carlos:** Necesitamos confirmar el destino de la información que está copiando, y quién le está pagando.
- **해석:** 그녀가 복사하고 있는 정보가 어디로 가는지, 그리고 누가 그녀에게 돈을 주고 있는지 확인해야 해.
- **주요 단어:** `confirmar` (동사) 확인하다 / `destino` (남성 명사) 목적지, 행방 / `copiar` (동사) 복사하다 / `pagar` (동사) 돈을 지불하다
- **문법:** 관계대명사 `que`(선행사 información). 간접의문문 `quién`(강세 유지). `le` = 간접목적격(그녀에게). 진행형 두 번.
- **시제:** `Necesitamos` → necesitar, 직설법 현재 1인칭 복수 / `confirmar` → 부정사 / `está copiando` → estar + copiar, 직설법 현재진행 3인칭 단수 / `está pagando` → estar + pagar, 직설법 현재진행 3인칭 단수
