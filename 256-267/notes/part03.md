## 장면 7. 엘레나에 대한 은밀한 감시
> 카를로스의 지시로 CNI가 은밀히 엘레나를 감시하기 시작합니다.

### 7-1. **Carlos:** (Llama a Álvaro) Tenemos vigilancia discreta sobre Elena, fuera de la central.
- **해석:** (알바로에게 전화한다) 본부 밖에서 엘레나를 은밀히 감시하고 있어.
- **주요 단어:** `llamar` (동사) 전화하다, 부르다 / `vigilancia` (명사, 여) 감시 / `discreto/a` (형용사) 은밀한, 눈에 띄지 않는 / `sobre` (전치사) ~에 대해, ~위에 / `fuera de` (전치사구) ~밖에서 / `central` (명사, 여) 본부, 본사
- **문법:** `llamar a + 사람`: 사람 목적어 앞의 전치사 a(인칭 a). `vigilancia sobre + 대상`: '~에 대한 감시'. `fuera de` + 명사로 장소 밖을 나타냄.
- **표현:** `tener vigilancia sobre alguien` '누구를 감시하에 두다'. `la central`은 정보기관·회사의 '본부'를 가리키는 구어적 표현.
- **시제:** `Llama` → llamar, 직설법 현재 3인칭 단수(지문) / `Tenemos` → tener, 직설법 현재 1인칭 복수

### 7-2. **Álvaro:** ¿Algún movimiento sospechoso?
- **해석:** 수상한 움직임이라도 있었어?
- **주요 단어:** `algún` (alguno의 어미 탈락형, 형용사) 어떤 / `movimiento` (명사, 남) 움직임 / `sospechoso/a` (형용사) 수상한, 의심스러운
- **문법:** `alguno`는 남성 단수 명사 앞에서 `algún`으로 줄어듦. 동사 없이 명사구만으로 된 의문문.
- **표현:** 동사를 생략한 짧은 질문(¿Hay algún…? 의 생략)으로 구어에서 흔함.
- **시제:** 동사 없음

### 7-3. **Carlos:** Anoche se reunió con un hombre en un aparcamiento, brevemente.
- **해석:** 어젯밤 그녀가 주차장에서 한 남자와 잠깐 만났어.
- **주요 단어:** `anoche` (부사) 어젯밤 / `reunirse` (재귀동사) 만나다, 모이다 / `aparcamiento` (명사, 남) 주차장 / `brevemente` (부사) 잠깐, 짧게
- **문법:** 재귀동사 `reunirse con + 사람` '~와 만나다'. 과거의 특정 시점(anoche)이므로 단순과거(부정과거).
- **표현:** `aparcamiento`는 스페인식 표현(중남미에서는 estacionamiento/parqueadero).
- **시제:** `se reunió` → reunirse, 직설법 단순과거 3인칭 단수

### 7-4. **Carlos:** Le entregó algo, aunque no pudimos ver exactamente qué.
- **해석:** 그에게 뭔가를 건넸는데, 정확히 무엇인지는 볼 수 없었어.
- **주요 단어:** `entregar` (동사) 건네다, 넘겨주다 / `algo` (대명사) 무언가 / `aunque` (접속사) ~이지만 / `poder` (동사) ~할 수 있다 / `exactamente` (부사) 정확히
- **문법:** `le`는 간접목적격 대명사(그 남자에게). `aunque` + 직설법: 사실인 양보. `qué`는 간접의문문의 생략형(qué le entregó).
- **표현:** `no pudimos ver` — poder의 단순과거 부정형은 '(시도했지만) 할 수 없었다'는 뉘앙스.
- **시제:** `entregó` → entregar, 직설법 단순과거 3인칭 단수 / `pudimos` → poder, 직설법 단순과거 1인칭 복수 / `ver` → 부정사

### 7-5. **Álvaro:** ¿Identificasteis al hombre?
- **해석:** 그 남자 신원은 확인했어?
- **주요 단어:** `identificar` (동사) 신원을 확인하다, 식별하다 / `hombre` (명사, 남) 남자
- **문법:** `al` = a + el, 사람 직접목적어 앞 인칭 a.
- **표현:** vosotros 활용(identificasteis)은 스페인식 2인칭 복수. 카를로스 개인이 아니라 그의 팀 전체에게 묻는 것.
- **시제:** `Identificasteis` → identificar, 직설법 단순과거 2인칭 복수(vosotros)

### 7-6. **Carlos:** Todavía no.
- **해석:** 아직.
- **주요 단어:** `todavía` (부사) 아직
- **문법:** 특이사항 없음
- **표현:** `Todavía no` '아직 아니다'는 짧은 부정 답변.
- **시제:** 동사 없음

### 7-7. **Carlos:** Viajaba con pasaporte que resultó ser falso, según comprobamos después.
- **해석:** 여권을 가지고 다녔는데, 나중에 확인해 보니 위조 여권이었어.
- **주요 단어:** `viajar` (동사) 여행하다, 이동하다 / `pasaporte` (명사, 남) 여권 / `resultar` (동사) ~로 드러나다 / `falso/a` (형용사) 가짜의 / `según` (전치사/접속사) ~에 따르면 / `comprobar` (동사) 확인하다, 검증하다 / `después` (부사) 나중에
- **문법:** 불완료과거(viajaba)는 배경 상황, 단순과거(resultó, comprobamos)는 완결된 사건. `que`는 관계대명사(선행사 pasaporte). `resultar + 부정사/형용사` '~인 것으로 판명되다'. `según` + 절.
- **표현:** `con pasaporte` 무관사 사용은 신분 서류 등에서 흔함. `resultó ser falso` '가짜로 드러났다'.
- **시제:** `Viajaba` → viajar, 직설법 불완료과거 3인칭 단수 / `resultó` → resultar, 직설법 단순과거 3인칭 단수 / `ser` → 부정사 / `comprobamos` → comprobar, 직설법 단순과거 1인칭 복수(현재형과 형태 같지만 después가 있어 과거)

### 7-8. **Álvaro:** Eso confirma que hay un contacto externo profesional detrás de esto.
- **해석:** 그건 이 일 뒤에 전문적인 외부 연락책이 있다는 걸 확인해 주는 거네.
- **주요 단어:** `confirmar` (동사) 확인하다, 입증하다 / `contacto` (명사, 남) 연락책, 접촉 / `externo/a` (형용사) 외부의 / `profesional` (형용사) 전문적인 / `detrás de` (전치사구) ~뒤에
- **문법:** `confirmar que` + 직설법(사실 확인). `hay`는 haber의 비인칭형 '~이 있다'. `eso`(앞 내용 전체), `esto`(현재 사건)는 중성 지시대명사.
- **표현:** `estar/haber alguien detrás de algo` '어떤 일의 배후에 누가 있다'.
- **시제:** `confirma` → confirmar, 직설법 현재 3인칭 단수 / `hay` → haber, 직설법 현재 3인칭 단수(비인칭)

### 7-9. **Carlos:** Exactamente.
- **해석:** 바로 그거야.
- **주요 단어:** `exactamente` (부사) 정확히 — 앞에서 설명
- **문법:** 특이사항 없음
- **표현:** 동의를 나타내는 맞장구.
- **시제:** 동사 없음

### 7-10. **Carlos:** Necesitamos identificar quién es antes de que la operación se complete.
- **해석:** 작전이 완료되기 전에 그가 누구인지 밝혀내야 해.
- **주요 단어:** `necesitar` (동사) 필요하다 / `identificar` 앞에서 설명 / `antes de que` (접속사구) ~하기 전에 / `operación` (명사, 여) 작전 / `completarse` (재귀동사) 완료되다
- **문법:** `necesitar + 부정사`. `quién es`는 간접의문문(악센트 유지). `antes de que`는 항상 접속법을 요구 → `se complete`. `se complete`는 재귀 수동적 용법.
- **표현:** 특이사항 없음
- **시제:** `Necesitamos` → necesitar, 직설법 현재 1인칭 복수 / `identificar` → 부정사 / `es` → ser, 직설법 현재 3인칭 단수 / `se complete` → completarse, 접속법 현재 3인칭 단수

### 7-11. **Álvaro:** ¿Cómo puedo ayudar desde dentro?
- **해석:** 내부에서 제가 어떻게 도울 수 있을까요?
- **주요 단어:** `cómo` (의문사) 어떻게 / `poder` 앞에서 설명 / `ayudar` (동사) 돕다 / `desde dentro` (부사구) 안에서, 내부로부터
- **문법:** `poder + 부정사`. `desde`는 기점 '~로부터'.
- **표현:** `desde dentro` '내부에서(잠입한 위치에서)'.
- **시제:** `puedo` → poder, 직설법 현재 1인칭 단수 / `ayudar` → 부정사

### 7-12. **Carlos:** Sigue observando a Elena.
- **해석:** 계속 엘레나를 지켜봐.
- **주요 단어:** `seguir` (동사) 계속하다 / `observar` (동사) 관찰하다, 지켜보다
- **문법:** `seguir + 현재분사` '계속 ~하다'. `a Elena`는 인칭 a. tú 명령형.
- **표현:** 특이사항 없음
- **시제:** `Sigue` → seguir, 긍정 명령형 2인칭 단수(tú) / `observando` → observar, 현재분사

### 7-13. **Carlos:** Si vuelve a acceder fuera de horario, avísanos de inmediato para coordinar vigilancia en tiempo real.
- **해석:** 그녀가 또 근무 시간 외에 접근하면 즉시 알려 줘, 실시간 감시를 조율할 수 있게.
- **주요 단어:** `volver a + 부정사` 다시 ~하다 / `acceder` (동사) 접근하다, 출입하다 / `horario` (명사, 남) 근무 시간, 일정 / `avisar` (동사) 알리다 / `de inmediato` (부사구) 즉시 / `coordinar` (동사) 조율하다 / `en tiempo real` 실시간으로
- **문법:** 조건문 `si + 직설법 현재, 명령형`(실현 가능한 조건). 긍정 명령형에는 대명사가 뒤에 붙음: avisa + nos → `avísanos`(강세 유지 위해 악센트 추가). `para + 부정사` 목적.
- **표현:** `fuera de horario` '근무 시간 외에'.
- **시제:** `vuelve` → volver, 직설법 현재 3인칭 단수 / `acceder` → 부정사 / `avísanos` → avisar, 긍정 명령형 2인칭 단수(tú) + nos / `coordinar` → 부정사

### 7-14. **Álvaro:** Entendido.
- **해석:** 알겠습니다.
- **주요 단어:** `entender` (동사) 이해하다
- **문법:** 과거분사 단독 사용(= Lo he entendido).
- **표현:** 지시를 받았을 때 '알겠다, 접수했다'는 뜻의 정형 표현.
- **시제:** `Entendido` → entender, 과거분사

### 7-15. **Álvaro:** Mantendré los ojos abiertos.
- **해석:** 눈 크게 뜨고 지켜볼게요.
- **주요 단어:** `mantener` (동사) 유지하다 / `ojo` (명사, 남) 눈 / `abierto/a` (형용사, abrir의 과거분사) 열린
- **문법:** mantener의 불규칙 미래형(tener형: mantendr-). 목적어 보어 형용사 `abiertos`가 `ojos`와 성·수 일치.
- **표현:** `mantener los ojos abiertos` '경계를 늦추지 않다'.
- **시제:** `Mantendré` → mantener, 직설법 미래 1인칭 단수

### 7-16. **Carlos:** Y Álvaro, ten mucho cuidado.
- **해석:** 그리고 알바로, 정말 조심해.
- **주요 단어:** `tener cuidado` 조심하다 / `mucho/a` (형용사) 많은
- **문법:** tener의 tú 불규칙 긍정 명령형 `ten`. `cuidado`가 남성 명사라 `mucho`.
- **표현:** `ten (mucho) cuidado` '(매우) 조심해'.
- **시제:** `ten` → tener, 긍정 명령형 2인칭 단수(tú)

### 7-17. **Carlos:** Si esto es una operación de inteligencia extranjera, el nivel de profesionalidad del otro lado será alto.
- **해석:** 이게 외국 정보기관의 작전이라면 상대편의 전문성 수준은 높을 거야.
- **주요 단어:** `inteligencia` (명사, 여) 정보(첩보), 지능 / `extranjero/a` (형용사) 외국의 / `nivel` (명사, 남) 수준 / `profesionalidad` (명사, 여) 전문성 / `lado` (명사, 남) 편, 쪽 / `alto/a` (형용사) 높은
- **문법:** 조건문 `si + 직설법 현재, 직설법 미래`. `del` = de + el. 미래형 `será`는 추측·예상의 뉘앙스도 있음.
- **표현:** `el otro lado` '상대편, 적측'. `inteligencia`는 여기서 '첩보·정보 활동'.
- **시제:** `es` → ser, 직설법 현재 3인칭 단수 / `será` → ser, 직설법 미래 3인칭 단수

### 7-18. **Álvaro:** Lo tendré presente.
- **해석:** 명심할게요.
- **주요 단어:** `tener presente` 염두에 두다, 명심하다
- **문법:** `lo`는 중성 직접목적격 대명사(앞의 충고 전체). tener의 불규칙 미래형 tendr-.
- **표현:** `tener algo presente` '~을 기억해 두다'.
- **시제:** `tendré` → tener, 직설법 미래 1인칭 단수

## 장면 8. 야간 접근 목격
> 며칠 후, 알바로가 늦게까지 남아 있다가 엘레나의 또 다른 야간 접근을 목격합니다.

### 8-1. **Álvaro:** (Trabajando hasta tarde, ve a Elena entrar en la sala de planos) Ahí está, otra vez fuera de horario.
- **해석:** (늦게까지 일하다가 엘레나가 설계도실로 들어가는 것을 본다) 저기 있네, 또 근무 시간 외에.
- **주요 단어:** `trabajar` (동사) 일하다 / `hasta tarde` 늦게까지 / `ver` (동사) 보다 / `entrar en` (동사) ~에 들어가다 / `sala de planos` 설계도실(도면실) / `ahí` (부사) 저기 / `otra vez` 다시, 또
- **문법:** 현재분사 구문 `Trabajando…` '일하던 중에'(동시 상황). 지각동사 `ver + 목적어 + 부정사`: '~가 …하는 것을 보다'. `Ahí está`는 estar로 위치 표현.
- **표현:** `Ahí está` '저기 있네/바로 그거야'. `fuera de horario` 앞에서 설명. `entrar en`은 스페인에서 흔한 형태(중남미는 entrar a).
- **시제:** `Trabajando` → trabajar, 현재분사 / `ve` → ver, 직설법 현재 3인칭 단수 / `entrar` → 부정사 / `está` → estar, 직설법 현재 3인칭 단수

### 8-2. **Álvaro:** (Llama en voz baja a Carlos) Carlos, Elena está en la sala de planos ahora mismo.
- **해석:** (작은 목소리로 카를로스에게 전화한다) 카를로스, 엘레나가 지금 막 설계도실에 있어요.
- **주요 단어:** `en voz baja` 작은 목소리로 / `ahora mismo` 바로 지금
- **문법:** 위치를 나타내는 estar. `llamar a Carlos` 인칭 a.
- **표현:** `ahora mismo` '바로 지금'(강조).
- **시제:** `Llama` → llamar, 직설법 현재 3인칭 단수(지문) / `está` → estar, 직설법 현재 3인칭 단수

### 8-3. **Carlos:** Perfecto.
- **해석:** 좋아.
- **주요 단어:** `perfecto/a` (형용사) 완벽한
- **문법:** 특이사항 없음
- **표현:** '좋아, 잘됐어'라는 동의·만족의 맞장구.
- **시제:** 동사 없음

### 8-4. **Carlos:** Mantén la distancia, pero intenta ver qué está haciendo, sin arriesgarte demasiado.

### 9-11. **Álvaro:** Tiene razón, debí avisarle.
- **해석:** 맞습니다, 미리 말씀드렸어야 했는데요.
- **주요 단어:** `tener razón` 옳다 / `deber` (동사) ~해야 하다 / `avisar` 앞에서 설명
- **문법:** `deber + 부정사`의 단순과거 `debí` '~했어야 했다'(하지 않은 일에 대한 후회). `le`는 usted에 대한 간접목적격, 부정사 뒤에 붙음.
- **표현:** `Tiene razón` '말씀이 맞습니다'(usted).
- **시제:** `Tiene` → tener, 직설법 현재 3인칭 단수(usted) / `debí` → deber, 직설법 단순과거 1인칭 단수 / `avisarle` → avisar, 부정사 + le

### 9-12. **Álvaro:** Fue una decisión de último momento, al notar el patrón de accesos que le mencioné.
- **해석:** 말씀드린 출입 패턴을 알아차리고 막판에 내린 결정이었습니다.
- **주요 단어:** `decisión` (명사, 여) 결정 / `de último momento` 막판의, 급히 정한 / `notar` 앞에서 설명 / `mencionar` (동사) 언급하다
- **문법:** `al + 부정사` '~했을 때, ~하면서'. `que`는 관계대명사. `le`는 usted에 대한 간접목적격.
- **표현:** `de último momento` '마지막 순간의, 즉흥적인'.
- **시제:** `Fue` → ser, 직설법 단순과거 3인칭 단수 / `notar` → 부정사 / `mencioné` → mencionar, 직설법 단순과거 1인칭 단수

### 9-13. **Mauricio:** (Asiente, aunque no del todo convencido) De acuerdo.
- **해석:** (완전히 납득하지는 않았지만 고개를 끄덕인다) 알겠습니다.
- **주요 단어:** `asentir` (동사) 고개를 끄덕이다, 동의하다 / `del todo` 완전히 / `convencer` (동사) 납득시키다 / `de acuerdo` 좋다, 동의하다
- **문법:** asentir는 e→ie 어간 변화 → `asiente`. `convencido`는 과거분사가 형용사로 쓰임(estar 생략).
- **표현:** `no del todo` '완전히는 아닌'. `De acuerdo` '알겠다, 좋다'.
- **시제:** `Asiente` → asentir, 직설법 현재 3인칭 단수(지문) / `convencido` → convencer, 과거분사

### 9-14. **Mauricio:** Por favor, la próxima vez, avíseme antes.
- **해석:** 다음번에는 부디 미리 알려 주세요.
- **주요 단어:** `próximo/a` (형용사) 다음의 / `vez` (명사, 여) 번, 회 / `avisar` 앞에서 설명 / `antes` (부사) 미리, 전에
- **문법:** usted 긍정 명령형(접속법 형태) avise + me → `avíseme`(악센트 추가).
- **표현:** `la próxima vez` '다음번에'.
- **시제:** `avíseme` → avisar, 긍정 명령형 3인칭 단수(usted) + me

### 9-15. **Álvaro:** Por supuesto, disculpe la descoordinación.
- **해석:** 물론입니다, 조율이 안 된 점 죄송합니다.
- **주요 단어:** `por supuesto` 물론 / `disculpar` (동사) 용서하다 / `descoordinación` (명사, 여) 조율 부족, 엇박자
- **문법:** usted 긍정 명령형 `disculpe`.
- **표현:** `Disculpe + 명사` '~에 대해 죄송합니다'(격식체 사과).
- **시제:** `disculpe` → disculpar, 긍정 명령형 3인칭 단수(usted)

### 9-16. **Mauricio:** No hay problema.
- **해석:** 괜찮습니다.
- **주요 단어:** `problema` (명사, 남) 문제 (-ma로 끝나는 남성 명사)
- **문법:** 비인칭 haber.
- **표현:** `No hay problema` '문제없어요, 괜찮아요'.
- **시제:** `hay` → haber, 직설법 현재 3인칭 단수(비인칭)

### 9-17. **Mauricio:** Solo quiero que todo quede bien documentado, para nuestra propia protección.
- **해석:** 저희 자신을 보호하기 위해서라도 모든 게 제대로 기록되길 바랄 뿐입니다.
- **주요 단어:** `solo` (부사) 단지 / `querer` (동사) 원하다 / `quedar` (동사) ~한 상태로 남다 / `documentar` (동사) 문서화하다, 기록하다 / `propio/a` (형용사) 자신의 / `protección` (명사, 여) 보호
- **문법:** `querer que` + 접속법(주어가 다를 때) → `quede`. `quedar + 과거분사` '~된 상태가 되다'. `documentado`는 todo와 일치.
- **표현:** `para nuestra propia protección` '우리 스스로를 보호하기 위해'.
- **시제:** `quiero` → querer, 직설법 현재 1인칭 단수 / `quede` → quedar, 접속법 현재 3인칭 단수 / `documentado` → documentar, 과거분사

### 9-18. **Álvaro:** Lo entiendo perfectamente.
- **해석:** 충분히 이해합니다.
- **주요 단어:** `entender` 앞에서 설명 / `perfectamente` (부사) 완벽히
- **문법:** `lo`는 중성 직접목적격 대명사(앞의 말 전체).
- **표현:** 특이사항 없음
- **시제:** `entiendo` → entender, 직설법 현재 1인칭 단수
